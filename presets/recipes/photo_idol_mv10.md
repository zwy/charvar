# photo_idol_mv10 · 照片变身打歌 MV 10 秒版（固定模板）

**两步固定文本生成配方**：没有随机选角、没有 LLM 写稿——提示词 A（首帧图）/提示词 B（10 秒视频）逐字铆在 YAML 里，一张用户照片进、一段 10 秒日系打歌 MV 出。移植自理定稿源文档（存档：`docs/照片变身打歌MV_10秒版_源文档.md`；模板内容全部逐字，未做改写）。随机版家族见 `random_mv_video_up`。

| 步 | 干什么 | manual |
|---|---|---|
| `refs 用户照片` | 配方级素材 `assets/user_photo.jpg`；步内按 label 引用 | — |
| `adhoc_image 首帧图` | 提示词 A 逐字 + 用户照片 i2i 参考图 → 16:9 特写首帧（**openrouter 钉 `openai/gpt-image-2.6-flare`**，实测 **$0.023**/张、1536×864）：极近面部特写不露肩、日系 idol 妆、粉蓝金舞台虚化、真人实拍高调质感 | **true** |
| `video_model 成片` | 提示词 B 逐字 + 首帧进 first_frame → heygen-video-1 **10s 768p 16:9**（heygen 目录价 $0.036/s，实测约折半 ≈ **$0.18**/条；480p ≈ $0.10 调试档） | **true** |

两个检查点正好覆盖特效语义：先验收首帧是不是本人、妆造裁切合格，再花真金白银出成片。单条全链成本 ≈ **$0.20**（首帧 $0.023 + 视频 $0.18）。

## 运行

```bash
charvar recipes run photo_idol_mv10
charvar recipes run photo_idol_mv10 --continue  # 出特写首帧（免费），验收辨识度/妆容/裁切
charvar recipes run photo_idol_mv10 --continue  # 提交 10s 成片作业并轮询（真金白银 ≈$0.18）
```

或顶栏「配方」页 → `photo_idol_mv10` → 开始运行 → 每个检查点「继续」。

## 换人 / 复用

- **换用户照片** = 替换 `presets/recipes/assets/user_photo.jpg`，然后重新 `recipes run` 建新运行（每次 run 全链重跑；素材缺失时步 gate 停 waiting）。
- **已有合格首帧想直接出片**：同 run 内 `--continue` 走 retry 幂等（首帧产物在就复用，不重复出）；或按 视频页手动提（首帧 + 提示词 B）。
- 当前 `user_photo.jpg` 是自合成测试人像（模板验证用）；真实用户照片直接同名替换。

## 模板固定内容（逐字铆在 YAML，改版先改源文档再同步）

- 10 秒 / 16:9 / 四镜头 **2+2+3+3 秒**；1 名主角 + 8 名伴舞；约 9 秒统一收势、末秒自然余摆、**不切黑**。
- **READY**（约 2 秒切镜强拍亮起、4 秒熄灭）→ **SHINE**（约 7.5 秒）两处背景屏大字；圆角粗体大写、不遮脸；除此之外无其他文字。
- 服装：主角「粉白星糖款」（珍珠白上衣/樱粉短外套/胸前蝴蝶结/银边粉白百褶短裙/白色短靴——注意**有短靴**，与服饰库的赤足系不同）；伴舞白色主体浅粉点缀简化款。
- 舞台：粉蓝金色华丽打歌舞台（对称灯阵、水晶装饰、层叠拱形灯框、中央背景屏）。
- **身份稳定设计**（源文档调优要点，保留）：主角不从远处人群走近、不甩头不转身、镜头只小幅推进——压制跨镜换脸的三类高发源。
- 质感锁逐字：`cinematic live-action，真人实拍电影感画质；high-key bright lighting…`（两段提示词里各嵌一份，A 段为柔光变体）。

## 注意

- **逐字红线**：两段提示词按定稿逐字采用，改一个字都可能破坏字卡样式/妆容/节奏——要改模板，先改源文档并存档，再重排 YAML（拼装与比对脚本见 git 历史本轮提交）。
- **跨模型保真**：源平台 ≠ 我们端（首帧 gpt-image-2.6-flare、视频 heygen-video-1）——字卡字体、妆容细节、舞台渲染以我们端实测为准，试跑记录见文件末尾。
- **首帧通路为什么钉 flare**：Qwen-Image-Edit（ComfyUI 通路）试跑不过验收清单——保构图保素颜的天性，肩颈衣服入画 + 日系妆没做出来；编辑系模型（flare）跟得动「极近特写重构图 + 改妆」两条硬要求，且是设置页已有 i2i 选择（$0.023/张）。换首帧模型改 `model:` 行即可。
- **音乐与声音段**：heygen 无声（`generate_audio: false`），该段当氛围理解、实际无音轨；换有声模型（`model:` 行改 veo-3.1 / kling 等标 `generate_audio` 的）后该段直接生效，条款无需改。
- **大字渲染是变量**：READY/SHINE 由视频模型渲染，崩字/未出现时换种子重跑首帧+成片（词形约束条款不动）。
- 首帧检查点验收清单（本人辨识度/双眼鼻嘴完整/肩颈无入画/粉蓝金舞台）见源文档 §6——首帧版本此前已获用户认可（源平台），我们端复现以本配方的运行产物为准。
- 源文档状态说明诚实保留：15 秒版曾获「脸好多了」反馈，但 **10 秒版在源平台也未实测验收**——本配方的试跑即全链首次实测；成片验收以 §6 视频清单逐条核对。
- 15 秒随机版资料包（词池/服饰家族/原片校准）见 `docs/打歌MV特效资料包.md`。
