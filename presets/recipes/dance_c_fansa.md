# dance_c_fansa · 舞蹈配方 C：饭撒摇（俏皮互动手势舞）

生成配方：单图首帧（ComfyUI/Qwen 图片编辑，免费）→ OpenRouter 视频模型直出（heygen/heygen-video-1，480p 5s ≈ $0.10）。

源自《单图舞蹈特效 Workflow：饭撒摇》（2026-10-24）。设计定位与 A/B 拉开差异：不再是固定手势舞，而是「招手 → 双食指指脸 → 双手开花摆掌」的三段**互动感**表演（像人物注意到镜头前的你，主动招呼、俏皮展示、开心回应），是 5 秒原创简化版，不冒充原版复刻。

charvar 变化只有一处并在此记录（沿用本工作流系列「修改提示词要记录」的约定）：首帧提示词里抖音的 `素材1` 替换为 charvar 通路的 `<image1>`（参考图 = yellow_dress_bob 档案「全身正面」槽位，经 `reference_labels: [front]` 注入）。视频提示词原文未动（"输入首帧" = 实际上传的生成首帧，即上游 adhoc_image 步产物）。

这版构图比 A/B 更近（头顶至腰部），让脸部表情与手势更突出；首帧直接摆好招手手位，减少视频开始后的准备动作。

## 运行

```bash
charvar recipes run dance_c_fansa --continue   # 首帧（ComfyUI，免费）
charvar recipes run dance_c_fansa --continue   # 视频作业（heygen 5s 480p；wait_s=420 内收片，超了再 continue 续查）
```

## 检查重点（原文第四节）

- **互动是否成立**：有「看到你 → 主动展示自己」的感觉，而不是三个孤立手势。
- **动作是否清楚**：招手、指脸、双手展开，能否看出顺序。
- **面部是否干净**：双手在脸颊外侧活动时，有没有挡脸、碰脸或带动五官变化。

时间点和招手次数是编排目标，以生成结果判断，不预先承诺精确执行。
