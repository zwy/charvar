# dance_d_zhuman · 舞蹈配方 D：珠满摇（轻盈摇摆 + 收势等夸）

生成配方：单图首帧（ComfyUI/Qwen 图片编辑，免费）→ OpenRouter 视频模型直出（heygen/heygen-video-1，480p 5s ≈ $0.10）。

源自《单图舞蹈特效 Workflow：珠满摇》（2026-10-24）。与前三支的区别：手臂向两侧打开、轮廓舒展（不再收在胸前/脸旁），收尾从「招呼」换成「我跳得好看吗，快夸我」的得意俏皮神态。是珠满摇意象的 5 秒简化改编版，不冒充原版复刻；「像蝴蝶，像孔雀」「快点夸我」等原口令不足以核对动作路径，故直接描述运动路径、不写舞蹈名称进提示词。古风换装按要求留到动作确认后单独扩展。

**方案状态**：提示词为未经生图/生视频检验的新稿——用户已授权「效果不 OK 可以调整」；改动按本系列约定记录在迭代表，同种子重测。

charvar 变化只有一处并在此记录：首帧提示词里抖音的 `素材1` 替换为 charvar 通路的 `<image1>`（参考图 = yellow_dress_bob 档案「全身正面」槽位，经 `reference_labels: [front]` 注入）。视频提示词原文未动（"输入首帧" = 实际上传的生成首帧，即上游 adhoc_image 步产物）。

## 运行

```bash
charvar recipes run dance_d_zhuman --continue   # 首帧（ComfyUI，免费）
charvar recipes run dance_d_zhuman --continue   # 视频作业（heygen 5s 480p；wait_s=420 内收片，超了再 continue 续查）
```

## 检查重点（原文第四节）

1. **展开的轮廓**：动作从胸前小动作真正变成舒展的两侧手臂。
2. **左右起伏**：能看出两侧交替，而不是双臂同时上下乱挥。
3. **收尾神态**：「跳完快夸我」的俏皮得意感，而不是例行歪头微笑。
4. **构图边界**：展开后双手仍在画面内。

这版先验证动作和神态，不绑定口型或精确歌词卡点。

```text
以输入首帧为唯一视觉依据，生成一段约5秒的单人轻盈摇摆舞视频。

画面连续性：
从输入首帧的姿态直接开始。保持人物的身份、五官、发型、体型、服装、背景、光线和整体画风一致。全程只有同一名人物，不换装，不新增头饰、披帛、道具或其他装饰。

镜头：
9:16竖版，正面平视固定镜头，一镜到底。保持首帧中头顶至大腿中段的构图和人物大小，不推拉、不摇移、不切镜头。人物始终位于画面中央附近，展开手臂时，双肘与双手仍留在画面内。

舞蹈整体：
人物面向镜头，完成一小段轻盈、俏皮、舒展的舞蹈。主要运动来自双臂向两侧展开、前臂交替轻抬、肩膀随动和小幅重心变化。动作柔和但有明确节奏，不拖沓，不是缓慢摆拍。

双脚留在原地附近，不走动、不跳跃、不转圈。躯干大部分时间正对镜头，脸部保持朝向镜头，不大幅扭腰，不后仰。

动作顺序：

0—1.5秒，轻轻展翅：
从首帧双手分开放在胸前下方的姿态开始，双膝轻轻屈伸，身体小幅回弹。
双手同时向各自一侧展开，肘部随之离开身体，形成柔和、舒展的双臂轮廓。
展开结束时，双肘略低于肩膀，肘部仍然弯曲，双手位于身体两侧，手指自然舒展，掌心斜向下。不要把双臂绷成一条水平直线，不抬手过头，不向镜头伸手。

1.5—3.5秒，左右轻摇：
保持双臂向两侧展开、双肘弯曲的基本轮廓。
画面左侧的前臂与手先轻轻抬高，另一侧略微放低；随后交换高低，画面右侧的前臂与手轻轻抬高，另一侧略微放低。
两侧的高度变化适中，双手不超过头部，不垂落到腰部以下。手腕随前臂轻轻起伏，不独立快速翻转，不做复杂绕腕。

身体重心随动作先向画面左侧轻移，再向画面右侧轻移，肩膀自然跟随。头部只有少量随动，眼神仍看向镜头，笑容逐渐明显。整体像展开的翅膀轻轻起伏，不是快速扑扇手臂。

3.5—5秒，收势等夸：
双臂从两侧自然收回，双肘靠近身体两侧，双手停在腰部上方、下胸部下方的身体前侧。
收回过程中，双掌自然转为斜向上，两只手保持分开，手指放松舒展。双手不相碰，不托下巴，不贴脸，不继续向镜头推出。

身体回到中央，头轻轻向一侧倾斜，眉毛略微抬起，露出自信、俏皮、略带得意的笑容，像刚跳完一小段舞，正在等镜头前的人夸奖。
保持嘴唇自然，不说话、不对口型。最后保留轻微肩膀回弹和自然呼吸，不突然冻结。

动作衔接：
双手从身体前方向两侧展开，接着完成左右交替起伏，再自然收回前侧，形成一条连续的动作路径。
每段之间不重新准备，不突然换姿势。头发和衣物随动作产生轻微自然的跟随变化。

手部与身体：
手指以自然舒展为主，不临时变成比心、指脸、猫爪或拳头。双手各自在身体一侧运动，不交叉，不从面部中央经过。肩膀放松，手臂关节自然弯曲。

避免出现：
手臂快速扑扇、双手举过头顶、复杂绕腕、手指反复张合、双臂交叉、突然转身、夸张扭腰顶胯、向前鞠躬，以及人物外观、服装或背景发生变化。
```
