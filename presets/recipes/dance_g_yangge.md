# dance_g_yangge · 舞蹈配方 G：秧歌

生成配方：单图首帧（ComfyUI 图片编辑，免费）→ OpenRouter 视频模型直出（heygen/heygen-video-1，480p 5s）。

本系列第七支，但**主体换人**：配方级主体是 `red_bob_glasses`（红发眼镜女人，卡通插画风），参考图取自该档案「全身正面」槽位（`refs: [{label: front, from: subject, slot: front}]`），经 `reference_labels: [front]` 注入首帧步。不用 `character_sheet`——四视图拼图会出多人。

走 **中式民间舞** 路线，与 A（摇摆拳）、B（猫爪）、C（饭撒摇）、D（珠满摇）、E（企鹅）、F（侧推比耶）都不同：靠「双手在身前交替画大圆 + 重心左右小幅移动」立形象，喜庆、舒展、不卖萌。秧歌的扇子、绸带、鼓点一律不加——人物双手不持物。

## 为什么选秧歌

1. **气质匹配**：卡通插画角色 + 中式民间舞，画风上更贴；秧歌的动作幅度大、左右对称，5 秒内辨识度高。
2. **避坑**：F 配方踩过「并排平移」两轮不生效（heygen 对抽象位移词响应差），秧歌核心动作是**画圆**——有轨迹、有落点、有比喻空间，比平移好表达。
3. **首帧可验证**：全身构图露出脚，能看出踏步是否离地、裙摆是否走光。

## 方案状态

**已定稿**（YAML `version: 3` = v2 提示词）。初版为未经生图/生视频检验的新稿，经三轮实跑收敛：

- **v1**（初版）：「画大圆」抽象表述 → 视频里变成体侧上下划拉，高度三次冲到脸旁。
- **v2**（定稿）：首帧换「扶大圆环」比喻 + 视频换「呼啦圈」比喻 + 落点锚定 + 高度锁 → 横向推收成立、高度不越界、收尾落定成立。**仅剩躯干跟着手转。**
- **v3**（试改后回退）：试图用「躯干不跟着手转」「双肘保持弯曲」两句修躯干转 → **变差**（高度又冲到脸旁），按本系列「两次未修即接受」的规矩回退到 v2 提示词。

已从本系列迭代经验中取用：

- **首帧手位用具象比喻**（F 的三轮教训：抽象位置词与几何约束都拉不动编辑模型的低手位先验，「捧球」一句生效）。本支用「两手分别扶着一个看不见的大圆环的两侧」，并附几何约束（手腕高于手肘、悬在身前不搭腰带）。
- **heygen 动作写成比喻 + 落点锚定**（F 的教训：「并排平移」不生效，「隔空推物」+ 落点一次成立）。本支用「转动一个看不见的呼啦圈」，落点锚在身体侧前方、离躯干约一掌远、高度腰线到胸口之间。
- **侧别中性化**（heygen 对「画面左侧/右侧的手」指向随机，F 的 v1/v3/v4/v5 两反一对）。本支全程不指定左右手，只说「向身体的一侧」。
- **收尾给硬时间点**（C/D/E 的经验）：4.0 秒前双手落定，4.2—5 秒只点头一次。
- **先过目首帧再放行视频**：首帧步 manual 检查点默认开，首帧不过目不放行视频（要花钱）。
- **两次未修即接受**（F 的 v3 经验）：v3 修躯干转失败即回退，不再硬拗。

## 本支特有的两条硬要求

红发眼镜女人是**卡通插画**角色，与 A—F 的真人/半写实主体不同，视频模型最容易在这两处漂：

1. **不许变写实**：首帧与视频提示词都明确要求保持深棕粗轮廓线、明暗分块、柔和渐变、暖色，禁止「真人照片 / 3D 渲染 / 写实摄影质感」。
2. **眼镜不许丢**：青绿色细边框长圆形眼镜是她的辨识特征，视频里镜框镜片消失/变形就算废片。

另外她穿紧身迷你裙，秧歌有重心移动和膝弹，容易被模型带出顶胯、掀裙、裙摆走光——都写进避免项。

## 运行

```bash
charvar recipes run dance_g_yangge              # 首次：建运行，停在首个检查点
charvar recipes run dance_g_yangge --continue   # 出首帧（ComfyUI，免费），再停在视频检查点
charvar recipes run dance_g_yangge --continue   # 视频作业（heygen 5s 480p；wait_s=420 内收片，超了再 continue 续查）
```

注意 `--continue` 是「续跑已有运行」，**首次必须不带这个参数**，否则报「没有可继续的运行」。

## 检查重点

1. **推收成立**：能看出「身前横向推出—收回」的完整节奏（左右各一次），不是双手在胸前随意划拉、也不是上下举过肩。
2. **重心跟随**：身体左右小幅移动随弧线走，脸始终朝镜头不转走。**躯干跟着手转是已知瑕疵**（v3 试修失败，已接受记录）。
3. **画风守住**：全程卡通插画风，没有中途变写实/3D；眼镜一直在脸上。
4. **收尾落定**：4.0 秒前双手回胸前并停住，4.2 秒后只有点头 + 笑，不追加动作。

**定稿结论（2026-10-24）**：**v2 提示词定稿**（YAML `version: 3`，内容与 v2 一致）。参考成片 `video_20261024-173504_27cd9923`（v2 成片，heygen 480p 5s，首帧 `adhoc_20261024-173422_eea19f2b`）；v1 成片 `video_20261024-173107_a2fea5db` 与 v3 成片 `video_20261024-173859_8c094edb` 留档对比。证据链：v1 抽象「画圆」不成立 + 高度三次冲脸旁 → v2 换「呼啦圈」具象比喻 + 落点锚定 + 高度锁 → **推收首次成立、高度不越界、收尾落定成立**（一项全过、两项过、一项部分）→ v3 加约束修躯干转 → 变差 → 按「两次未修即接受」回退。

**可复用经验**：

- **画圆/绕环类抽象动作用「看不见的呼啦圈」这类具象比喻**——F 支的「隔空推物」比喻同样有效，两者共同点：给模型一个**已存在于其先验里的物体/动作模板**，并配「落点 + 高度上限」，比抽象方向词（画、绕、平移）有效得多。
- **「高度上限」必须写成具体部位**（不超过锁骨 / 不举到肩上 / 不抬高到脸旁），泛泛的「不要太高」无效。
- **给模型加约束可能反而引入新毛病**：v3 加「双肘保持弯曲」→ 手臂做高做小、高度又跑脸旁。**修动作高度时不要同时加肢体姿态约束**，一次只改一个变量。
- **首帧两手合十会让「两手分开」类的视频动作更难成立**——v2 首帧明确分开后，视频推收的双手间距才稳。首帧的手部几何直接影响视频里的手部几何。
- **卡通角色配视频模型：画风与眼镜是首要防漂项**，两处都在首帧与视频提示词里各写一遍（显式禁止「真人照片 / 3D 渲染」），本支三次实跑全程守住。

<summary>v1 生成视频提示词（原文存档）</summary>

```text
以输入首帧为唯一视觉依据，生成一段约5秒的单人秧歌视频。

画面连续性：
从输入首帧的姿态直接开始。保持人物的身份、五官、发型、体型、服装、鞋子、背景、光线和整体画风一致。全程只有同一名人物，不换装，不新增配饰或道具。
保持首帧的卡通插画风格：深棕色粗轮廓线、明暗分块清晰、柔和渐变的皮肤和布料、暖色。全程不要变成真人照片或 3D 渲染。
人物脸上的眼镜全程佩戴在脸上，镜框和镜片不消失、不变形、不换款式。

镜头：
9:16竖版，正面固定镜头，一镜到底。
保持首帧的全身构图和人物大小，头顶、双手、鞋尖与脚跟始终在画面内，地面保持稳定，不推拉、不摇移、不切镜头，不追随人物移动。

整体表演：
人物面向镜头，完成一小段喜庆、舒展的秧歌。
主要动作是双手在身前交替画大圆，配合重心的左右小幅移动和膝部的轻弹。像在身前推动一个看不见的大圆盘：双手从身体正前方出发，向身体一侧画一个完整的圆弧，落到身体侧前方腰部的高度，再从身侧画回身体正前方。圆弧经过的最高点在胸口附近，不高于肩膀。
身体的重心随圆弧的走向小幅移到对应一侧再回到中间，躯干基本保持正面，脸始终朝向镜头。
脚下的步子是小幅的左右踏步，脚不离地，不走动、不跳跃、不转身。

动作顺序：

0—1.2秒，起势：
从首帧胸前托举的姿态直接开始，双膝轻轻屈伸一次，身体小幅下沉再回弹。
双手同时从身体正前方开始向身体的一侧画圆，前臂从肘部向上带出，划到身体侧前方腰部的高度。双手始终保持分开、不相碰、不交叉。
身体重心随之小幅移到那一侧，肩膀和胸口自然跟随，脸始终朝向镜头。

1.2—2.6秒，第一个整圆：
双手从身体侧前方继续画圆，绕过身体下前方回到身体正前方胸前的高度，完成一个完整、连贯的大圆。
重心随之回到中间，再小幅移到另一侧。圆弧最高点不超过肩膀高度，双手不越过身体两侧的轮廓，不向镜头推近。
头发和衣物随身体运动产生轻微自然的跟随变化。

2.6—4.0秒，第二个整圆：
用同样的方式向另一侧再画一个完整的大圆，动作连贯不中断，节奏比第一个略快、幅度相当。
膝部继续轻弹，重心左右小幅移动，双脚只在原地做小幅度踏步，不向前走远，不滑行。

4.0—5秒，收尾亮相：
```
