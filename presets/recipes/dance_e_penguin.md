# dance_e_penguin · 舞蹈配方 E：企鹅舞（认真表情 + 憨憨摇摆）

生成配方：单图**全身**首帧（ComfyUI/Qwen 图片编辑，免费）→ OpenRouter 视频模型直出（heygen/heygen-video-1，480p 5s，实测 $0.05/次）。

源自《单图舞蹈特效 Workflow：企鹅舞》（2026-10-24）。反差路线：人物不换装、不变企鹅、不丑化，表情认真淡定，动作却像小企鹅左右摇摆、小步侧点——笑点来自「跳得很认真，但动作有点憨」。与前四支的关键区别：**首次要求全身首帧（头顶到鞋底）**，因为节奏主要靠脚步侧点，腰部/大腿中段裁切会砍掉脚部信息；原文明确不许用之前那种裁切首帧代替。不安排双脚交叉、快速碎步、转圈、蹲跳。

**方案状态**：提示词为未经生图/生视频检验的新稿——用户已授权「效果不 OK 可以调整」；改动按本系列约定记录在迭代表，同种子重测。D 配方已验证的经验可在迭代时取用（硬时间点、收尾段锁景别重复强调）。

charvar 变化只有一处并在此记录：首帧提示词里抖音的 `素材1` 替换为 charvar 通路的 `<image1>`（参考图 = yellow_dress_bob 档案「全身正面」槽位，经 `reference_labels: [front]` 注入）。视频提示词原文未动（"输入首帧" = 实际上传的生成首帧，即上游 adhoc_image 步产物）。

## 运行

```bash
charvar recipes run dance_e_penguin --continue   # 全身首帧（ComfyUI，免费）
charvar recipes run dance_e_penguin --continue   # 视频作业（heygen 5s 480p；wait_s=420 内收片，超了再 continue 续查）
```

## 检查重点（原文第四节）

1. **全身完整**：侧点步时鞋尖、脚跟有没有出框。
2. **左右点步成立**：有没有「迈出—点地—收回」三段，而不是两只脚一起滑。
3. **手臂轮廓**：低位、小幅外张的企鹅翅膀，而不是展翅飞翔。
4. **反差好笑**：人物保持正常认真、动作有点憨；不依赖夸张表情。

这支先不加冰面、企鹅群或动物变身。

```text
以素材1中的人物为唯一主体，生成一张用于后续企鹅拟态舞蹈视频首帧的单人全身竖版图片。

人物身份与画风：
保留素材1中人物的五官特征、脸型、发型、发色、肤色、原有体型与个人辨识度，不替换成统一的网红脸，不改变人物的性别表达，不夸张改变头身比例，不通过增胖、缩短四肢或改变面部制造搞笑效果。
真人照片保持自然真实的摄影质感，绘画角色保持原有绘画风格。

人物服装：
沿用素材1中人物可见的服装，保持款式、颜色、领口、袖型和图案。原图没有展示的下装自然补全为与现有服装协调的日常下装，双脚穿简洁平底鞋。
不擅自换成黑白配色，不添加企鹅服、动物头套、翅膀、喙或其他动物装饰。人物双手不持物。

构图与镜头：
9:16竖版，正面平视，单人居中，全身完整入镜，从头顶到鞋底均清楚可见。头顶和鞋底下方留出适量空间，人物两侧留出小步侧移和前臂外摆的空间，不裁切手指、鞋尖或脚跟。
人物站在平整地面上，镜头保持正常透视，不俯拍、不仰拍，不使用广角畸变。

起始姿态：
人物面向镜头，自然站立，双脚左右分开约一个脚掌的间隔，脚尖基本朝向前方，双脚完整接触地面。双膝略微放松，上身直立，身体重心位于中间，不深蹲、不弯腰、不撅臀。

双上臂位于身体两侧，靠近躯干但不夹紧。双肘轻微弯曲，前臂向身体外侧略微张开，双手停在髋部两侧附近，位置略低于腰部。
双手自然舒展，手指略微并拢，指尖斜向下，手掌侧面朝向镜头。形成低位、小幅外张的企鹅翅膀轮廓，不抬高手臂，不做猫爪或握拳姿态。

表情与视线：
人物直视镜头，头部端正，表情认真、平静，嘴唇自然闭合，像已经准备好严肃地表演一支舞。不要皱眉生气，不做鬼脸，不提前大笑。

背景与光线：
简洁明亮的室内背景，浅色墙面，平整清楚的地面，脚下有自然接触阴影。没有其他人物、镜面反射或杂乱物品。
柔和均匀的光线，人物全身和双脚清楚可见。

最终画面：
正常人物认真准备跳企鹅拟态舞的瞬间。保持人体比例、服装结构和双手双脚自然，没有文字、水印、拼图或动作残影。
```

```text
以输入首帧为唯一视觉依据，生成一段约5秒的单人企鹅拟态舞蹈视频。

画面连续性：

人物始终保持原本人类外观，不变成企鹅，不新增动物装饰，不改变身材比例。全程只有同一名人物。

镜头：
9:16竖版，正面固定镜头，一镜到底。
保持首帧的全身构图和人物大小，头顶、双手、鞋尖与脚跟始终在画面内。地面保持稳定，不推拉、不摇移、不切镜头，不追随人物移动。

整体表演：
人物以认真、淡定的表情完成一小段轻快的企鹅拟态舞。
搞笑感来自低位外张的双臂、小幅左右摇摆和短促的侧点脚步，不通过鬼脸、身体变形或摔倒制造笑点。

躯干始终朝向镜头，头部大致保持正面。上身保持直立，双膝柔和放松，不深蹲、不弯腰、不撅臀，不夸张扭腰顶胯。

动作顺序：

0—0.6秒，认真起势：
从首帧姿态开始，双膝轻轻屈伸一次，身体小幅下沉再回弹。
双上臂保持靠近躯干，前臂顺势向外轻轻张开一点，再回到低位外张的基本姿态。双手保持在髋部两侧附近，不抬到胸前。
人物保持认真表情，直接进入节奏，不先垂手再重新准备。

0.6—2.2秒，左侧点步：
画面左侧的脚向左侧迈出一小步，以前脚掌轻点地面，不踢腿，不向前伸腿。
身体和头部随之向画面左侧小幅倾移，另一只脚留在原地支撑。双肩保持放松，身体像小企鹅一样轻轻侧摆。
随后点地的脚收回起始位置，身体回到中央。
双臂配合身体轻轻摆动，上臂不大幅抬起，双手始终在腰部以下。

2.2—3.8秒，右侧点步：
换成画面右侧的脚向右侧迈出一小步，以前脚掌轻点地面。
身体和头部随之向画面右侧小幅倾移，另一只脚留在原地支撑。
随后点地的脚收回起始位置，身体回到中央。
动作与前一侧形成左右对应的摇摆节奏，不交叉双腿，不连续向一侧走远，不滑行。

3.8—5秒，淡定收尾：
双脚回到起始站位，双膝再轻轻弹动一下。
双上臂仍靠近身体，左右前臂同时向外轻摆，再收回低位外张的基本姿态，像小企鹅短短地摆了一下翅膀。
人物头部轻轻向一侧倾斜，仍看向镜头，嘴角最后只浮现一点不明显的笑意，像认真跳完后在等评价。
保留自然呼吸和轻微身体余动，不突然冻结，不鞠躬。

运动要求：
整段动作保持在原地附近，左右两次点步的距离都较短。每次点步都有清楚的抬脚、点地和收回过程，不让鞋底沿地面滑行。
身体的左右移动来自脚步和重心变化，不让头部、躯干和双腿彼此脱节。
手臂摆幅小于身体两侧预留空间，双手不经过身体前方，不碰撞大腿。

表情与手部：
大部分时间保持认真、淡定，最后才出现少量笑意。不张嘴对口型，不挤眼，不吐舌，不做夸张鬼脸。
双手保持自然舒展，手指略微并拢，不反复变成拳头、猫爪或比心。

避免出现：
变成企鹅、身体增胖或缩短、双腿交叉、快速碎步、双脚同时离地、蹲跳、转圈、摔倒、鞋底滑行、手臂大幅扑扇，以及人物外观、服装、鞋子或背景发生变化。
```
