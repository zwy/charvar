# random_absurd_video · 随机荒诞动作视频

五步的**生成配方**（末步 `video_model`）：从「人脸 × 自建荒诞动作池 × 服饰」随机挑一套，
出一张荒诞动作**起势**首帧，直出一支 8 秒的搞笑动作挑战视频。
**针对池而不是某条**——每跑一次运行换一批选角；YAML 里不写死任何一条脸/动作/服饰。

| 步 | 干什么 | manual |
|---|---|---|
| `pick` 随机选库 | face-db-01 `face` 正面像选 1 条 + **荒诞动作文本池**（`studio` 库 `荒诞挑战` 分类的文本动作，`allow_text: true`，描述随库存天然齐备）选 1 条 + 实写服饰库（春/夏/秋/冬/パーティ，**剔水着与セクシー**）选 1 条 | false |
| `scene_design` 场景设计 | LLM 按动作起势+动作名+服饰出一段场景/光照文本；`hint:` 钉方向——开阔、安全、地面干净平整的真实场地，人物前方留出活动空间（爬行/翻滚类动作全靠地面） | false |
| `combo_image` 首帧图 | 组合流出图，**文本动作锚**：人脸=身份锚、动作描述=姿势锚（无姿势参考图，`build_prompt` 文本锚路径）、服饰=换装锚；`strip_accessories` 剥离包帽手持物 + `framing_extra` 全身入镜四周余白（爬行/翻滚不裁）；ComfyUI 2k 9:16 | **true** |
| `video_script` 视频脚本 | **看图脚本**（`frame_from: 首帧图`）+ 大幅档（`amplitude: large`）；片段类型从荒诞标签池掷骰（挑战赛/模仿秀/运动会/肢体喜剧）；LLM 按起势描述里的「下一拍」句编 8 秒动作脚本 | false |
| `video_model` 成片 | 脚本当 prompt + 首帧当 frame → OpenRouter 视频异步作业（`heygen/heygen-video-1` 写死，**8s 768p**，实测 ≈$0.018/s，一条约 $0.14） | **true** |

## 运行

```bash
charvar recipes run random_absurd_video            # 随机选库 + 场景设计，停在「首帧图」检查点
charvar recipes run random_absurd_video --continue # 出首帧 + 写脚本，停在「成片」检查点（此时可在网页看脚本）
charvar recipes run random_absurd_video --continue # 提交视频作业并轮询（真金白银）
```

或顶栏「配方」页 → 「random_absurd_video」→ 开始运行 → 弹层里逐步「继续」。

## 安全层（防封，先读这段）

昨天发小红书差点封号的教训：**安全靠池子准入，不靠事后措辞**。

1. **动作白名单**：`presets/poses/studio/` 里 `fu_*` 条目就是白名单本体——每条都是
   人工写了起势、人工审核语境才入库的；LLM 只在池内编动作，不自由发挥。**新增动作
   必须人工过审**；趴姿/爬行类条目一律带「模仿比赛」语境并写明双腿并拢等克制措辞。
2. **safety_lock 双头铆**（本配方新机制）：`combo_image` 与 `video_script` 各声明
   同一组安全条款——首帧提示词尾部与脚本 brief 都注入【安全红线（全程一致）】段，
   脚本输出要求追加「逐条落进『避免出现』节」，把安全写进视频提示词本体。
   多镜脚本不接（解析期报错）。
3. **服饰池收窄**：`categories: [春, 夏, 秋, 冬, パーティ]`，水着/セクシー类不进池。
4. **发布人工把关**：配方产出只是素材；发布标题建议用「挑战/运动会」语境包装。

发不出去/被限流的内容特征（写池子时避开）：趴撅臀、倒立裙装、贴墙劈叉类易走光姿势；
痛苦、惊恐、受伤叙事；任何性暗示肢体接触。

## 动作池结构

每条 `fu_*.yaml` 的 `action_text` = **起势段**（身体事实+机位事实，80–200 字）+
**蓄势句**「……下一拍将开始 X」——首帧提示词与脚本姿态锚共用这一段：首帧模型照着起势
出图，脚本 LLM 按「下一拍」句编动作。标题=动作名（进 brief 【动作】行）。现有 24 条：

- 拟兽类：蛙跳前进 / 螃蟹横跳 / 企鹅摇摆 / 大鸟扑翼 / 猩猩步 / 毛毛虫蠕动 / 四足爬行 / 低姿匍匐
- 滚翻类：原地侧滚三圈 / 草坡团身滚落 / 抱膝打挺弹起
- 失控机械类：机械人卡顿 / 倒放式倒退跑 / 无形磁铁拖拽 / 香蕉皮打滑虚惊 / 空气蛙泳
- 运动喜剧类：无绳跳绳 / 空气跨栏 / 原地快速自转 / 一二三木头人 / 假装断电倒弹 / 空气拔河 / 高抬腿踏步 / 相扑马步跺脚

新条目照 `docs/姿势库.md` 的「动作描述怎么写」范式写（先看同类条目再动笔），
写好 `charvar pose import-studio` 灌库即可进池。

## 随机语义

- 掷骰子种子 = 运行种子 + `recipe_run_id`：**每次运行换一批**；同一运行内 continue 固定同一批。
- 复现某批：记运行的 seed 与 run_id；`--seed <n>` 换种子重掷。
- 动作池锁 `studio` 库 `荒诞挑战` 分类；`allow_text: true` 时文本动作入池且要求描述
  已写好（本库描述随镜像走，天然齐备）；姿势图动作不受影响（`allow_text` 与姿势图池可叠加）。

## 换池 / 调流程（改 YAML 后重建运行）

- 荒诞度不够：往池子里加条目（白名单准入）；或改 `video_script.types:` 的喜剧标签池。
- 首帧风格：`style_lock:` 两处同改（combo_image 与 video_script，现在铆 cinematic live-action / high-key bright）。
- 安全条款：`safety_lock:` 两处同改（同上两步）；**改完想想新动作会不会触线**。
- 服饰池：`costume.categories:`；关场景设计：删两处 `scene_from:`。
- 关检查点：对应步 `manual: false`（首帧崩了也会烧视频费，斟酌）。
- LLM（场景 / 脚本）走 设置页「LLM」组 > env 默认链；看图脚本要求视觉模型，可按步 `model:` 覆盖。

## 注意

- 中途某步 failed：修好后「继续」重跑该步，不换批。
- `video_model` 提交即 202 作业；`wait_s: 600` 内收片，超时转 waiting 下次继续续查。
- 首帧是**文本锚**出图（无姿势参考图）：起势文本对不上的产出，回炉改该条目的
  `action_text`（`charvar pose action fu_xxx --set '…' --source studio` 或网页动作库编辑）；
  个别条目首帧稳定性差时，再考虑给它挂姿势图锚（二期 `pose_ref` 增强）。
- 爬行/蠕动类动作实测对模型最难：若位移感弱，先换池里其他动作试，不改措辞。
