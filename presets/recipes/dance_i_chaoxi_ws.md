# dance_i_chaoxi_ws · 舞蹈配方 I：潮汐引力（白裙丝袜版）

生成配方：单图首帧（ComfyUI 图片编辑，免费）→ OpenRouter 视频模型直出（heygen/heygen-video-1，480p 5s）。

配方级主体 `white_skirt_stockings`（白裙丝袜女人，**真人摄影风**），参考图取自该档案「全身正面」槽位（`refs: [{label: front, from: subject, slot: front}]`），经 `reference_labels: [front]` 注入首帧步。不用 `character_sheet`——四视图拼图会出多人。

**本配方是 `dance_f_chaoxi`（潮汐引力 · v5 定稿版）的真人摄影改编版**：动作结构、比喻、落点锚定、侧别中性、收尾硬时间点**逐字沿用 F 支 v5**（F 支实测四项检查点全过），只把画风段换成真人摄影、并把服装/丝袜/鞋锁定改成本角色的。

## 为什么选潮汐引力

松弛、自信、克制的酷感路线——和她成熟丰满、白缎面丝袜的气质最搭；而且「双脚留在原地不跳动」正好适配她 4cm 厚底高跟鞋的稳定站姿。收尾的单手肩旁比耶也是全系列里最利落的一个造型。

## 本支特有的三条硬要求

1. **不许变插画**：首帧与视频提示词都明确要求保持真人摄影质感，禁止「插画 / 动漫 / 3D 渲染」。
2. **丝袜不许消失/变网袜**：裸肤色薄透连脚丝袜 + 连续高光带是角色锁定的核心特征。
3. **鞋不许脱**：裸杏色厚底高跟露趾鞋（方形厚底、鞋头开放露趾、粗方跟）。**半身构图下模型会自行渲染全身并把鞋脱掉**（v1 实测），所以最终定稿用全身构图锁住鞋。

## 方案状态

**已定稿**（YAML `version: 3`）。三轮实跑：

- **v1**：F 支 v5 提示词直移，构图「头顶至大腿中段」。**动作四项检查点基本全过**（推收高度稳、收尾比耶成立），但模型自行渲染了全身并**把鞋脱了**（光脚）。
- **v2**：裁切改硬（「画面下缘在膝盖上方约一拳处截断，画面里看不到任何脚」）。**光脚问题解决**，但**推收高度飘了 4 帧**（2.0s 双手到脸旁）——半身构图里没有腿和鞋做参照，手部动作的相对幅度被放大。
- **v3**：改回**全身构图** + 显式锁定鞋（沿用 H 支已验证「全身构图保鞋」的做法）。定稿。

**本支最重要的发现**（与 H 支同源）：

> **首帧手位的高度 = 视频里推收动作的高度上限。**
>
> 本支首帧用 F 支验证过的「捧球」句式（手在胸口正下方），所以推收高度一开始就稳在胸口附近——这是 F 支「捧球比喻一次成功」的复现。

> **全身构图比半身构图更保服装，也更压得住手部高度。**
>
> 三个数据点：H 支全身 → 高度守住（1 帧偏高）；I 支 v1 全身 → 高度守住（1 帧偏高）；I 支 v2 半身 → 飘 4 帧。画面里有腿和鞋做参照时，模型的手部动作幅度会被压住；裁到腰以上就容易飘。

已从本系列迭代经验中取用：

- **首帧手位用「捧球」具象比喻**（F 支教训：抽象位置词与几何约束拉不动编辑模型的低手位先验，「捧球」一句生效）。**本支沿用 F 支原句，一个字没改就立住了**。
- **heygen 动作写成比喻 + 落点锚定**：「像隔空推开一件看不见的东西」+ 落点「身体左侧、离躯干约一掌远、高度在胸口附近」。
- **侧别中性化**（heygen 对「画面左侧/右侧的手」指向随机，F 支 v1/v3/v4/v5 两反一对）。收尾比耶写「一只手留在腰部附近，另一只手顺势抬到同侧肩膀外侧」，不指定左右。
- **收尾给硬时间点**：4.3 秒前落定，4.3—5 秒只点头一次。
- **两次未修即接受**（F 支 v3 经验）。

## 运行

```bash
charvar recipes run dance_i_chaoxi_ws              # 首次：建运行，停在首个检查点
charvar recipes run dance_i_chaoxi_ws --continue   # 出首帧（ComfyUI，免费），再停在视频检查点
charvar recipes run dance_i_chaoxi_ws --continue   # 视频作业（heygen 5s 480p；wait_s=420 内收片，超了再 continue 续查）
```

注意 `--continue` 是「续跑已有运行」，**首次必须不带这个参数**，否则报「没有可继续的运行」。

## 检查重点

1. **推收成立**：能看出「隔空推物」式的横向推出—收回，两手并排、间距不变、高度在胸口附近，**不冲到脸旁**。
2. **重心跟随**：躯干基本正面不跟着手大转，脸始终朝镜头。
3. **服装零漂移**：白裙/荷叶边/藏青滚边/浅黄蝴蝶结/裸色丝袜/**裸杏厚底露趾鞋**全程在位；裙长不变、不走光。
4. **收尾落定**：4.3 秒前单手比耶落到肩旁（手肘下沉、手指端约眼线高度、不贴脸不遮眼），保持到结束。

**定稿结论（2026-10-24）**：**v3 提示词定稿**（YAML `version: 3`）。参考成片 `video_20261024-181643_27a345aa`（v3 成片，heygen 480p 5s，首帧 `adhoc_20261024-181530_b8ac2b5a`）；v1 成片 `video_20261024-180318_82e1c39f`（动作最干净但光脚）与 v2 成片 `video_20261024-181057_5b75427b`（半身无脚、推收飘 4 帧）留档对比。证据链：v1 F 支 v5 提示词直移 → 动作四项全过但**光脚**（半身构图下模型自行渲染全身并脱鞋）→ v2 裁切改硬 → 光脚解决但**推收高度退步**（半身无参照，手部幅度失控）→ v3 改回全身构图 + 显式锁鞋 → **两个问题同时解决**，定稿。

**三版取舍**：v1 的推收高度最干净（1 帧偏高）但光脚；v2 无脚但飘 4 帧；v3 飘 2 帧但鞋在位。**选 v3**——鞋是角色设定的一部分，光脚是明确的设定违背，而「手到肩/耳侧」在可接受范围内（未到脸旁）。

**可复用经验**：

- **全身构图 > 半身构图**：全身保住了鞋；半身不仅丢了鞋，还让手部动作幅度失控。要展示鞋、要压住手部高度，优先全身。
- **同一个「捧球」句式在真人主体上一样成立**：F 支（yellow_dress_bob）→ I 支（white_skirt_stockings）原句直移即立住。**已验证的句式可以跨主体复用，只需按主体的服装/特征改锁定段**。
- **编辑模型无视「不入镜」类负向构图约束**：v1 明确写「膝盖、小腿和双脚不入镜」，模型仍渲染了全身。要控制画幅得用**正向的截断描述**（「下缘在膝盖上方约一拳处截断」「看不到任何脚」），负向说法会被弱化。
- **改构图会连带改变动作质量**：v2 只改了裁切，却让推收高度退步。**构图不是孤立的画面参数，它给模型提供了身体参照系**。
- **改构图 = 改首帧 = 重跑整条链**：首帧提示词变了就要重新出首帧（ComfyUI 免费）再重跑视频（$0.05），不能只重跑视频步。
