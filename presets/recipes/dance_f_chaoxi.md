# dance_f_chaoxi · 舞蹈配方 F：潮汐引力（酷感节奏手势舞）

生成配方：单图首帧（ComfyUI/Qwen 图片编辑，免费）→ OpenRouter 视频模型直出（heygen/heygen-video-1，480p 5s ≈ $0.05）。

源自《单图舞蹈特效 Workflow：潮汐引力》（2026-10-24）。本系列第六支，走 **酷感** 路线，与猫爪（萌感）、饭撒摇（热情招呼）、企鹅舞（认真反差）拉开区别：不卖萌，靠干净的「侧推—回收」×2、肩膀胸口小幅律动和收尾**单手比耶+轻轻点头**的松弛亮相。创作意象「一推一收，像被节奏牵引」。

两点边界沿用原文：① 做成《潮汐引力》主题的 5 秒原创简化改编，**不冒充原版复刻、不承诺自动卡点**（公开资料不足以核对原版完整动作；具体音乐片段选定后再讨论重音放侧推还是比耶亮相）；② **不强制换西装**（保留用户原衣服），不添加墨镜、首饰、手套。首帧构图回到**头顶至大腿中段**（A—D 同款半身，非 E 的全身）——本支双脚不动，只比手。

**方案状态**：提示词为未经生图/生视频检验的新稿——用户已授权「效果不 OK 可以调整」；改动按本系列约定记录在迭代表，同种子重测。已验证经验可在迭代取用：收尾段给硬时间点（C/D/E）、动作写成完整运动路径+硬禁令（D/E）、避免项要给豁免口径（E 扇翅）、先过目首帧再放行视频。

charvar 变化只有一处并在此记录：首帧提示词里抖音的 `素材1` 替换为 charvar 通路的 `<image1>`（参考图 = yellow_dress_bob 档案「全身正面」槽位，经 `reference_labels: [front]` 注入）。视频提示词原文未动（"输入首帧" = 实际上传的生成首帧，即上游 adhoc_image 步产物）。

## 运行

```bash
charvar recipes run dance_f_chaoxi --continue   # 半身首帧（ComfyUI，免费）
charvar recipes run dance_f_chaoxi --continue   # 视频作业（heygen 5s 480p；wait_s=420 内收片，超了再 continue 续查）
```

## 检查重点（原文第四节）

1. **推收清楚**：能看出「推出—收回」一次完整节奏，不是双手在胸前随意横移。
2. **身体跟随**：肩膀和胸口小幅参与，但脸始终朝镜头不转走。
3. **比耶干净**：只在最后出现、位于肩旁，不贴脸、不挡脸。
4. **气质区分**：整体松弛、自信，不是饭撒摇的热情招呼，也不是猫爪舞的萌感。

这版先不添加潮水、星空、引力光效或背景切换；不验证卡点。

动作顺序：

0—1.6秒，向画面左侧推收：
从首帧胸前下方的双手姿态直接开始，双膝轻轻弹动。
双手保持分开，一起移向画面左侧，手掌自然转向移动方向，做一次短促、轻巧的侧推。

1.6—3.4秒，向画面右侧推收：
接着双手一起移向画面右侧，手掌自然转向移动方向，完成一次对应的短促侧推，再收回胸前下方。
双手之间保持间隔，不相碰、不交叉。肩膀与胸口自然跟随，重心小幅向右移动，再回到中央。

3.4—5秒，肩旁比耶亮相：
双手从胸前自然落向腰部上方。
画面左侧的手留在腰部附近；画面右侧的手顺势抬到同侧肩膀外侧，伸出食指和中指形成自然的V形手势，其余手指自然弯曲。
比耶的手与脸部轮廓保持清楚间隔，不贴脸，不遮住眼睛，不伸向镜头。
