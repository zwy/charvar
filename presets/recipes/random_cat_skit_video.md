# random_cat_skit_video · 随机贱猫小品视频

五步的**生成配方**（末步 `video_model`）：随机掷出**一只随机生成的猫**（外观池掷骰）
× 一段**拟人贱剧小剧本**（自建文本池）→ 无参考图出一张猫首帧 → 直出一段 8 秒
反转喜剧视频。与 `random_cat_video`（猫做夸张动作）不同，这里猫是**成精的拟人演员**：
每条动作是一段**三拍小剧本**（起手 → 假动作/转折 → 贱兮兮定格），卖点是转折与贱格，
不是动作幅度。**针对池而不是某条**——每跑一次换一批；YAML 里不写死任何一条。

| 步 | 干什么 | manual |
|---|---|---|
| `pick` 随机选库 | **只抽动作**：`studio` 库 `荒诞猫剧本` 分类的文本动作（`allow_text: true`，18 条剧本池）掷 1 条；没有 face/costume 目标——猫外观不在库里 | false |
| `scene_design` 场景设计 | LLM 按动作描述+动作名出场景/光照文本；`hint:` 钉方向——猫真实可及的生活化场地（客厅/桌前小方桌/厨房台面/社区街边），市井喜感 | false |
| `combo_image` 首帧图 | **猫版无参考图首帧**（`subject_kind: cat`）：外观池**掷骰出随机猫**（12 种，掷骰 key 固定 = 首帧与脚本同一只）+ 剧本起手定格文本 = 全部锚（`build_cat_prompt`，ComfyUI 纯文生图 2k 9:16）；**首帧 = 起手瞬间**（举瓶 / 递爪 / 抱气球……剧本的开演定格） | **true** |
| `video_script` 视频脚本 | 看图脚本（`frame_from: 首帧图`）+ `amplitude: skit`（**剧本三拍规则**：起手充分 / 转折突然 / 贱兮兮收尾定格）+ `subject_kind: cat`；类型池掷骰小品标签 | false |
| `video_model` 成片 | 脚本 + 首帧 → OpenRouter 视频异步作业（`heygen/heygen-video-1`，8s 768p；实测 ≈$0.018/s，一条约 $0.14） | **true** |

## 剧本池结构（18 条三拍小剧本）

每条 `action_text` = 起手定格（首帧锚）+ 机位事实 + 三拍剧本句（「下一拍将开始…转折…收尾定格」）。
口味分布：舞蹈贱（站立贱舞/假砸绝技/偷鱼庆祝/空指挥官）· 互动戏弄（击掌诈骗/冲镜挑衅⚠️）·
魔幻现实主义（响指灭烛/激光魔术/煎饼电话/气球炸毛/尾巴救场/霸座液体瘫）· 拟人喜剧
（麻将出千/顶书走秀/牙签大佬/按铃装乖/吓人自坑/披风翻车）。

新条目照现有写法扩池，写好灌库：`python3 -m charvar.cli pose import-studio`
（注意 `import-studio` 是 upsert，**删条目前先动仓库文件**，否则 DB 里剩孤儿行仍在掷骰池）。

## 舞台逆推（首帧背景跟着剧本走）

**每条动作描述的起手句自带舞台**（假砸→深夜饭馆卡座木桌旁、霸座→地铁车厢空座、
门铃→自家门口玄关、指挥官→清晨斑马线、牙签大佬→饭馆门口、顶书→铺地毯的走廊……），
动作文本同时喂给场景步 / 首帧构建 / 脚本 brief 三处，背景自动与剧本同台。
`scene_design.hint:` 只写**逆推规则**（"动作描述里写明的舞台就是场景本身，别默认客厅"），
不列举固定场地——枚举式 hint 会把所有条目压回同一个客厅。扩池新条目照此写舞台。

## 与 random_cat_video 的差别

- 动作池分類不同（`荒诞猫剧本` vs `荒诞猫挑战`），两配方互不串池。
- `video_script.amplitude: skit`：规则 5–7 换剧本三拍版（**只接猫**，人版配 `skit` 直接
  parse 报错——措辞专配双足拟人表情戏，与 large 的四足大幅规则互斥）。
- `safety_lock` 换小品版：「砸/打/摔/抢」一律是假动作、道具不碎不伤猫——剧本里有
  假砸脑袋、摔坐、抢鱼这类笑点，条款锚死「没真发生」。
- 首帧 = **起手定格**（有戏剧张力的一帧），脚本从这一帧续演三拍。

## 运行

```bash
python3 -m charvar.cli recipes run random_cat_skit_video            # 择动作 + 场景，停在「首帧图」
python3 -m charvar.cli recipes run random_cat_skit_video --continue # 出猫首帧 + 写脚本，停在「成片」
python3 -m charvar.cli recipes run random_cat_skit_video --continue # 提交视频作业并轮询（真金白银）
```

## 安全层（防封）

同猫版机制（动作白名单 + safety_lock 两头铆 + 人工把关）。⚠️ 剧本池里 `cat_runby_taunt`
（冲镜挑衅）收尾是**竖中指手势**——平台对粗俗手势有低俗判定风险，且猫爪拟人手势渲染
不稳；这条是**点名保留的试验条目**，过目时想留想删再定，删掉即从池里消失。

## 已知风险

- 三拍剧本 8 秒内拍得完吗：转折句都写得短促（一寸处收住/闪电缩爪），heygen 对
  「假动作→转折」的节奏还原是首期最大未知——单条验证，节奏拖了就改条目转折句。
- 表情戏（贱笑/挑眉）依赖模型对猫脸微表情的还原；不达标就退回 `random_cat_video` 的
  大幅度动作路线。
