# random_cat_skit_video · 随机贱猫小品视频

五步的**生成配方**（末步 `video_model`），**脚本先行**：随机掷出**一只随机生成的猫**
（外观池掷骰）× 一段**拟人贱剧小剧本**（自建文本池）→ **先写视频脚本（人工过目，
创作主轴在这一步花零成本）** → LLM 按**已定稿脚本**设计场景 → 按场景+起手出**猫首帧**
（人工过目）→ 直出 8 秒反转喜剧视频。与 `random_cat_video`（猫做夸张动作）不同，
这里猫是**成精的拟人演员**：每条动作是一段**三拍小剧本**（起手→假动作/转折→贱兮兮定格），
卖点是转折与贱格，不是动作幅度。**针对池而不是某条**——每跑一次换一批；YAML 不写死任何一条。

| 步 | 干什么 | manual |
|---|---|---|
| `pick` 随机选库 | **只抽动作**：`studio` 库 `荒诞猫剧本` 分类（`allow_text: true`，26 条剧本池）掷 1 条；没有 face/costume 目标 | false |
| `video_script` 视频脚本 | **无图写稿**（无 `frame_from`）：视觉 LLM 只吃动作全文（含三拍尾段）+ `amplitude: skit` 剧本三拍规则 + 外观自掷（**掷骰 key 与首帧步同一把 = 同一只猫**，【主角·外观】进 brief）；类型池掷骰小品标签。**0–8s 分秒脚本在这里定稿，人工过目/改稿** | **true** |
| `scene_design` 场景设计 | LLM 按动作 + **`script_from: 视频脚本`（已定稿脚本为最高依据：拍点的舞台/道具/方位都要装得下）** + hint 逆推规则出场景/光照文本 | false |
| `combo_image` 首帧图 | 猫版无参考图首帧：外观掷骰（同 key 复现脚本那只猫）+ `action_anchor: setup`（**只锚起手+机位段**，剧本尾段不进图）+ 场景 + 双锁 → ComfyUI 纯文生图 2k 9:16；**首帧必须装得下脚本的 0 秒** | **true** |
| `video_model` 成片 | 脚本 + 首帧 → heygen-video-1，8s 768p（实测 ≈$0.018/s，一条约 $0.14） | **true** |

## 为什么脚本先行

- **创作主轴前置**：贱剧的灵魂在脚本（拍点/转折/表情戏）；0 成本阶段看过目/改稿，
  改脚本比改首帧便宜得多。
- **场景跟着脚本**：脚本拍点（比如贱舞绕圈、放瓶到桌）直接约束场景设计——场景不再
  猜动作，是「给已定稿的戏搭台」。
- **首帧最后定**：起手段只负责「0 秒是哪一帧」，与脚本零秒拍点天然同源（同一段动作
  文本的起手句）；首帧崩了重掷不影响已定稿的脚本。

## 剧本池结构（26 条三拍小剧本）

每条 `action_text` = 起手定格（首帧锚）+ 机位事实 + 三拍剧本句（「下一拍将开始…转折…收尾定格」）。
口味分布：舞蹈贱（站立贱舞/假砸绝技/偷鱼庆祝/空指挥官）· 互动戏弄（击掌诈骗/冲镜挑衅）
· 魔幻现实主义（响指灭烛/激光魔术/煎饼电话/气球炸毛/尾巴救场/霸座液体瘫）· 拟人喜剧
（麻将出千/顶书走秀/牙签大佬/按铃装乖/吓人自坑/披风翻车）· **拟人捣乱**（推书下架/
抽屉叼袜/抱枕翻车/屁股键盘/噤声偷吃/拖把驾马/胶带自坑/洗衣篮滑板——真猫捣乱梗的双腿
拟人版，装无辜的贱格归这类；四足真猫版在 [random_cat_naughty_video](random_cat_naughty_video.md)）。

## 舞台逆推（首帧背景跟着剧本走）

**每条动作描述的起手句自带舞台**（假砸→深夜饭馆卡座木桌旁、霸座→地铁车厢空座、
门铃→自家门口玄关、指挥官→清晨斑马线、牙签大佬→饭馆门口、顶书→铺地毯的走廊……）。
脚本先行后场景链是：动作起手句（自带舞台）→ 脚本拍点（道具/方位细化）→ `script_from`
把脚本交给场景 LLM → 首帧装进这个台里。`scene_design.hint:` 只写逆推规则，不列举固定场地。

## 机制要点

- 外观与首帧的一致性靠**掷骰 key 固定**（`{run_id}:appearance`）：脚本步与首帧步各滚
  同一把骰子，结果恒相同；`video_script.appearance` 记进步 outputs（可从 manifest 查）。
- `action_anchor: setup`：整段动作文本进首帧时尾段的瘫/躺/跑姿势会把额外的猫召唤进
  图片（实测地铁霸座翻车）；setup 只锚首个「下一拍」之前的起手+机位段。
- **`crowd: backdrop`（市井合理性）**：公共舞台条目（地铁霸座/冲镜挑衅/空指挥官/牙签大佬/
  响指灭烛）的起手段自带「远景虚焦人物剪影、与猫零互动」提示；`crowd: backdrop` 放开
  首帧禁人句与脚本硬规则的「不出现人类」，换成「远景、虚焦、零互动」——地铁里不能
  只有一只猫（判定：真空场不合理）。私人场合条目（客厅/玄关/厨房）保持 solo 措辞。
- `safety_lock` 小品版：「砸/打/摔/抢」一律是假动作、道具不碎不伤猫；⚠️ 池里
  `cat_runby_taunt`（冲镜挑衅）收尾是竖中指手势——**用户拍板中文语境不算违规，保留**。

## 运行

```bash
python3 -m charvar.cli recipes run random_cat_skit_video            # 掷动作 + 写脚本，停在「场景设计」——先过目脚本（零成本）
python3 -m charvar.cli recipes run random_cat_skit_video --continue # 按脚本设计场景，停在「首帧图」——过目场景文本
python3 -m charvar.cli recipes run random_cat_skit_video --continue # 出猫首帧，停在「成片」——过目首帧
python3 -m charvar.cli recipes run random_cat_skit_video --continue # 提交视频作业并轮询（真金白银）
```

停点语义 = 过目**上一步的成品**（gate 停在 manual 步之前）：第一次停点看的是脚本，
第二次看场景文本，第三次看首帧，最后放行成片。网页顶栏「配方」页同样逐步「继续」。

网页顶栏「配方」页 → 「random_cat_skit_video」→ 逐步「继续」。

## 换池 / 调流程

- 更换外观池：`combo_image.appearances:`；改喜剧标签：`video_script.types:`。
- 质感/安全条款：`style_lock:` / `safety_lock:` 两处（video_script 与 combo_image）同改。
- 视频模型：`video_model.model:`（换即梦 Seedance 或 OpenRouter 目录其他模型；注意该模型的
  时长/分辨率枚举）。

## 已知风险

- 脚本无图写稿时 0 秒拍点与首帧的贴合靠「起手段同源」保证：首帧与脚本对不上就重掷
  首帧或手改脚本（脚本已定稿，改脚本不影响已花成本）。
- 三拍剧本 8 秒内拍得完吗：转折句都写得短促；heygen 对「假动作→转折」的节奏还原有
  波动，重掷即换一版（重计费）。
- 表情戏（贱笑/挑眉）依赖模型对猫脸微表情的还原；不达标就退回 `random_cat_video` 的
  大幅度动作路线。
