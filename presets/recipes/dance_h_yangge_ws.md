# dance_h_yangge_ws · 舞蹈配方 H：秧歌（白裙丝袜版）

生成配方：单图首帧（ComfyUI 图片编辑，免费）→ OpenRouter 视频模型直出（heygen/heygen-video-1，480p 5s）。

配方级主体 `white_skirt_stockings`（白裙丝袜女人，**真人摄影风**），参考图取自该档案「全身正面」槽位（`refs: [{label: front, from: subject, slot: front}]`），经 `reference_labels: [front]` 注入首帧步。不用 `character_sheet`——四视图拼图会出多人。

**本配方是 `dance_g_yangge`（秧歌 · 卡通角色版）的真人摄影改编版**：动作结构、比喻、落点锚定、收尾硬时间点全部沿用，只把画风段换成真人摄影、并把服装/丝袜/鞋锁定改成本角色的。

## 为什么选秧歌

白缎面 + 双层荷叶边飞袖 + 深藏青滚边 + 浅黄缎带蝴蝶结 —— 这套装的中式舞台感和秧歌的喜庆气质天然契合；秧歌的动作是横向平推的舒展幅度，配她成熟松弛的气质不显轻浮。

## 本支特有的三条硬要求

她的辨识特征是「**白缎面连衣裙 + 裸肤色薄透连脚丝袜 + 裸杏色厚底高跟露趾鞋**」，视频模型三处都容易漂：

1. **不许变插画**：首帧与视频提示词都明确要求保持真人摄影质感，禁止「插画 / 动漫 / 3D 渲染」（卡通版 G 的对应条款是禁止变写实，方向相反）。
2. **丝袜不许消失/变网袜**：裸肤色薄透连脚丝袜 + 那条连续高光带是角色锁定的核心特征，首帧与视频各写一遍。
3. **裙子不许变短、不许走光、蝴蝶结不许掉**：紧身迷你裙 + 动作容易带出掀裙和走光，都写进避免项。

## 方案状态

**已定稿**（YAML `version: 2`）。初版经两轮实跑收敛：

- **v1**：首帧用「扶大圆环」比喻 + 视频用「呼啦圈」比喻。**推收的高度失控**——0.5—2.0s 双手三次冲到脸旁/头顶。
- **v2**：首帧比喻换回 F 支验证过的「**捧球**」句式把手位拉高，落点锚到「胸口附近」，并加「双手不举过头顶」。**推收路径变水平，高度守住**。定稿。

**本支最重要的发现**（G 支的延伸）：

> **首帧手位的高度 = 视频里推收动作的高度上限。**
>
> v1 首帧手落在腰腹髋部，视频模型要把手「推」到腰胸高度需要一段上升，结果直接冲过头顶（0.5—2.0s 连续四帧在脸旁/头旁）；v2 首帧手抬到胸口下缘后，横向推收的高度就稳在胸口附近。首帧的手部几何**直接传染**给视频里的手部几何——这与 `dance_g_yangge` v1→v2 的结论是同一条。

已从本系列迭代经验中取用：

- **首帧手位用「捧球」具象比喻**（F 支教训：抽象位置词与几何约束都拉不动编辑模型的低手位先验，「捧球」一句生效；G 支 v1 用「扶圆环」就没拉住）。
- **heygen 动作写成比喻 + 落点锚定**（F 支教训：「并排平移」不生效，「隔空推物」+ 落点一次成立）。
- **侧别中性化**（heygen 对「画面左侧/右侧的手」指向随机，F 支 v1/v3/v4/v5 两反一对）。本支全程不指定左右手。
- **收尾给硬时间点**：4.0 秒前双手落定胸前，4.2—5 秒只点头一次。
- **两次未修即接受**：v2 后仍有「躯干跟着手转」的瑕疵（与 G 支 v2 同款），接受并记录，不再硬拗。

## 检查重点

1. **推收成立**：能看出「身前横向推出—收回」的完整节奏（左右各一次），路径是平的水平线，不是上下挥、也不是举过肩。
2. **高度守住**：双手全程在胸口附近活动，**不举过头顶、不冲到脸旁**（v1 的主要失败点）。
3. **重心跟随**：身体左右小幅移动随弧线走，脸始终朝镜头。**躯干跟着手转是已知瑕疵**（与 G 支同款，已接受记录）。
4. **服装零漂移**：白裙/荷叶边/藏青滚边/浅黄蝴蝶结/裸色丝袜/裸杏厚底鞋全程在位；裙长不变、不走光、不掀裙。
5. **收尾落定**：4.0 秒前双手回胸前并停住，4.2 秒后只有点头 + 笑，不追加动作。

**定稿结论（2026-10-24）**：**v2 提示词定稿**（YAML `version: 2`）。参考成片 `video_20261024-180745_a796f9c0`（v2 成片，heygen 480p 5s，首帧 `adhoc_20261024-180643_7da8dbfb`）；v1 成片 `video_20261024-175933_e678b426` 留档对比。

**可复用经验**：

- **首帧手位高度 = 视频动作高度上限**（本支核心发现，G 支结论的延伸）：首帧手低 → 视频动作整体上飘冲脸旁；首帧手到胸口附近 → 视频推收稳在胸口附近。**改视频动作的高度之前，先看首帧的手位**。
- **同一个比喻在不同主体上不一定通用**：「扶大圆环」在卡通角色 G 上立住了，在她身上没立住（落到腰腹）；换成 F 支的「捧球」立刻生效。**比喻要按主体的参考图先验选**——参考图的手位越低，越要用「手已经被抬起来」的句式（捧球/托着），而不是「手在某个高度」。
- **全身构图比半身构图更保服装，也更压得住手部高度**：H 支全身构图保住了裸杏色厚底鞋，推收高度也守住（仅 1 帧偏高）；I 支 v2 改半身后不仅丢了鞋，推收还飘了 4 帧。画面里有腿和鞋做参照时，模型的手部动作幅度会被压住；裁到腰以上就容易飘。**要保鞋、也要压住手部高度，优先用全身构图。**
- **卡通角色改真人主体时，画风段要整段重写**：不能只把「卡通插画风」删掉，要换成明确的「保持真人摄影质感 + 禁止插画/动漫/3D 渲染」，否则模型会往插画方向漂。
