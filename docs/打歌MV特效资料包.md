# 「照片变身打歌 MV」特效资料包

> **交接文档** · charvar 项目整理，2026-11-07。
> 用途：交给负责实现该特效的 Agent。特效规格如下——**用户上传一张自己的照片 → 先生成一张首帧图 → 再基于首帧图 + 视频提示词生成 15 秒视频**。模板内容固定（本文档 §2 锁定），受托方 deliver 两个提示词：**提示词 A（出首帧图）** 与 **提示词 B（出生成视频）**。
> 本资料包的素材来自 charvar 视频配方 `random_mv_video_up`（随机选角 MV 升级版）的实测运行——结构、构图红线、扫光节奏、文字特效、质感锁全部**在同一条管线上真跑验证过**（两轮真金白银成片）。

---

## 1. 特效流程与两个提示词的分工

```
用户照片（1 张，人像）
   │
   ├── 提示词 A + 用户照片 → 首帧图（图生图 / i2i）
   │      16:9 · 面部大特写（只露脸不露肩）· 轻柔定妆光 · 高调明亮实拍质感
   ▼
   首帧图
   │
   ├── 提示词 B + 首帧图 → 15 秒成片（图生视频 / i2v）
   │      16:9 · 4 个镜头 · 特写扫光开场 → 齐舞编舞 → 两处背景大字 → 亮相收尾
   ▼
   15s 打歌 MV
```

- **提示词 A（首帧图）**：锚定对象是**用户照片**（与照片同一人）；输出特写首帧。首帧里**不出现服装**（特写只露脸）。
- **提示词 B（视频）**：锚定对象是**提示词 A 的产出首帧图**；服装、伴舞、编舞、大字全部由文字条款驱动（实测成立）。

## 3. 提示词 A（首帧图）：结构 + 底稿

### 3.1 结构（四段，按序拼接）

```
A1 身份锚（对用户照片，勿用库条目措辞）
A2 特写构图段（§3.2 逐字）
A3 质感锁（§2 表三条，逐字）
A4 场景背景段（§3.3） + 画面禁令句
```

### 3.2 A2 特写构图段【逐字】

> 采用面部大特写构图：画面被脸部充满——从额头到下巴，额头贴近画面上缘、下巴贴近画面下缘，五官清晰、眼神有神采，肤质与发丝质感自然真实；构图比脸部参考照更紧：脖子、肩、锁骨一律不进入画面（不露肩膀，肩颈不入画，下巴以下没有任何身体部位）；浅景深，背景柔化虚化；只呈现这一名角色的面部，不出现第二个人。

（三重防露肩约束是实测教训：首跑曾在参考照自带裸肩时出肩，加「构图比脸部参考照更紧」后修复。）

### 3.3 A4 场景背景段【逐字】 + 禁令句

> 开阔的礼堂舞台，浅色抛光地面泛着柔和反光，纵深留有宽敞空间，背景为简约浅色幕布与几道细白栅栏。明亮偏暖的舞台面光从前方均匀铺亮，节奏感的粉蓝轮廓光与地面光斑交替闪动，明暗对比轻快通透，青春可爱。

> 不要出现人体结构辅助线、关节圆圈或素体模型效果；避免多余手指、多余肢体、关节扭曲及手臂与头部粘连。

### 3.4 A1 身份锚（对用户照片——**此段未实测，受托方定稿**）

实测管线用的人脸库条目锚句是：「<image1>为角色脸部参考，保留该角色的面部特征、发型、发色和整体美术风格，确保生成的是同一个角色，不要擅自更换造型。」特效版的语义差别：照片是真人本人、不是库风格条目，锚定要强调**同一人**而非同一画风。建议方向（措辞自定）：

- 与上传照片同一人：五官、脸型、肤色、发型发色一致，只做打光、构图与画质重制，不改变长相/不整形；
- 照片非清晰正脸时的兜底（选正脸单人照 / 拒收多人照）由受托方产品逻辑决定；
- 输出是高调明亮实拍风格（A3 保证），不要把真人照片转成二次元。

## 4. 提示词 B（视频）：结构 + 必含条款

### 4.1 结构

**底稿直接用 §7.2 实测定稿脚本**（真金白银验证过的版本），按下面 4 个「替换槽位」改内容：

| 槽位 | 在底稿哪里 | 怎么替换 |
|---|---|---|
| ① 身份/发型 | 第 1 段开头「严格保持附图面部特征、同发型……」 | 视频模型的身份来源是**首帧图**（不是用户照片），所以这句话不用改——它锚的就是首帧。发型如「同发型」即可，因为镜1特写只露脸，发型一致性由首帧接续保证 |
| ② 服装 | 第 1 段「同服装（白色水手偶像上衣……；white sailor idol top, ……）」 | 换成 §5 选定套装的「中文并列；keywords 原文」——中文给模型直感、英文关键词保真（实测模式） |
| ③ 文案词对 | 镜3「背景布景墙面上浮现……『SHINE』」+ 镜4「浮现超大粗体无衬线大写『HIT』」+ 配乐段尾句 | 固定 SHINE/HIT（推荐，实测渲染成功）或从 §6 池子重掷 |
| ④ 镜1 时长 | 四镜各 3.75s 均匀分 | 可改「镜头一（0秒至3秒）」并顺延后面切点；整体总时长保持 15s |

### 4.2 必含条款清单（自审）

- [ ] 开头一句锚定首帧 + 同场景同光同调色 + 首席不混入人群 + 切镜不换背景光线
- [ ] 结构总述一句（特写起势 → 切镜爆发 → 主段 → 末镜亮相定格）
- [ ] 镜1：特写构图句 + **扫光条款逐字**（§2 表「扫光」行）
- [ ] 镜2：首席独舞（伴舞未入画），起始延续切镜拍

## 6. 文案词池资料（背景大字）

- **全池**：`HIT / OWN IT / SHINE / GO GO / LOVE`（超短大写英文词出字最稳）。
- **实测渲染成功**：SHINE + HIT（768p，两处均为**粉色闪粉填充**质感，贴合原片）。
- **次成功**（480p 对照）：LOVE + HIT（渲染成了霓虹描边风格而非闪粉填充；480p 分辨率下出字质感整体差一档）。
- 词形约束：超大粗体无衬线大写、亮色闪粉与辉光质感、贴背景墙面、不遮挡首席面部与队形核心、每镜一处、全片除这两处无其他文字。
- 原片的词是 HIT（中段）+ OWN IT（末镜），原片大字工艺描述「soft pink sparkling edge snapping into alignment」（粉色闪粉**弹入对齐**）——受托方若想还愿可把镜3词写「弹入对齐（snap into alignment）」动效描述，未实测。

镜头二（3.75秒至7.5秒）：切到全景全身，平视机位接跟拍后退；首席独舞，伴舞尚未入画。起始延续切镜拍：身体正面朝镜头、头部端正居中，两侧手臂上抬、肘部外展、前臂后弯、双手手掌抚在后颈，手肘略高于肩线，躯干挺直无扭转，双腿与肩同宽直立分开、膝盖自然微屈、双脚平踩、脚尖微外撇、重心均匀，正面平视，上臂在头两侧形成部分遮挡。随即在强拍松开双手，双臂向两侧大幅展开，做一次轻快跨步跳与小幅转体，甩头回正，再接左右交替上步、双臂上下挥动和弹跳；动作幅度从起势快速放大，裙摆与泡泡袖随跳跃摆动，面部从明亮微笑进入节奏性张嘴笑，四肢与手指结构连贯清楚。

## 10. 待拍板 & 注意事项

### 10.1 待拍板（模板定格前需要用户或受托方确认）

1. **服装定哪套**：推荐「糖果摇滚」（桃红×银闪，与 MV 粉系高调最贴）或「星光节拍」（藏青×金，剧场感最强）；其余 4 套打歌服 + 8 套基础款见 §5。定哪套只影响提示词 B 的槽位②。
2. **镜1 时长定档**：2.5s（贴原片）还是 3.75s（实测均匀 4 等分）。建议 3s 上下、四镜时长一并定死。
3. **是否要收尾黑场**：原片有硬切黑场，现定稿是无黑场自然收束（实测）；要黑场可在镜4 尾句加「约15秒处画面快速切黑定格」，未实测。
4. **伴舞数量**：实测条款为 4 名；原片约 9 名。4 名已验证稳定。

### 10.2 已知风险与教训清单（给受托方）

1. **露肩复发风险**：提示词 A 必须保留三重构图约束（§3.2 逐字）——首跑曾在参考照自带裸肩时出肩，加约束后修复。
2. **扫光写法**：条款里「单次扫完，不频闪、不往复」不可删——模型自作主张改成往复扫会明显偏离原片。
3. **特写首帧不吃服装**：服装全靠提示词 B 文字驱动；图与文字若有偏差以文字为准。想让服装更稳可试「平铺图作视频参考图」通路（§5.1，未实测）。
4. **质感条款逐字嵌入**：LLM 改写曾把英文 token（live-action/high-key）改写成等义中文——受托方若管线里也过 LLM 改写，需加「逐字采用，不得改写或拆散」的保护指令。
5. **大字渲染是最大变量**：分辨率越高出字质感越好（480p 描边 → 768p 闪粉填充）；崩字换词对重跑即可，别动词形约束条款。
6. **用户照片不可控**（非正脸/多人/低清）——受托方需设计入口侧校验或提示词兜底。
7. 全部抽帧自验用 §7.3 的 ffmpeg 命令，别直接看原片抽原始分辨率帧（大且慢）。
