# 服装预设与贴字

`charvar/outfit.py` 与 `charvar/overlay.py` 的字段参考。**只写当前有效定义**——历史在 git log 里。
工作约定与红线见仓库根的 `AGENTS.md`。

两者都是出图后的组合能力，服务于「视频配方」的合成流水线（出图批 → 贴字 → 本地合成 reel）。

## 服装预设

`presets/outfits/*.yaml`。每条 = 英文服装描述段 `text` + 中文 `label`（贴字/展示用）+
可选 `caption_tags`（id → 英文 caption token，缺省 = id）。

子目录家族，**不进主预设下拉**（`list_presets` 只扫 `presets/actions/`）。

## 跨预设笛卡尔积

出图请求带 `outfit_preset`（+ `outfit_order`）：

| `outfit_order` | 变体顺序 |
|---|---|
| `outfit_first`（缺省） | 每件服装连播全部动作 |
| `pose_first` | 每个动作连播全部服装 |

- 变体 id = `{outfit_id}__{pose_id}`（`pose_first` 时反序）。
- caption 在 pose 之后插 outfit token。
- meta 带 `outfit` / `outfit_label`。
- 语义：`POST /generate`（带 outfit_preset）= `charvar gen --outfit … --outfit-order …`；
  网页生成页「服装预设 + 组合顺序」同源。变体顺序就是后续 reel 合成的播放顺序。

## 贴字

`presets/overlays/*.yaml`。PIL 确定性后处理，**不改原图**。

产物落 `<data>/generated/<run_id>/labeled/{index:06d}.png`（scene 白名单含 labeled）。

| 字段 | 说明 |
|---|---|
| `position` | `left_top` / `right_top` / `left_bottom` / `right_bottom` / `center` |
| `margin_x` / `margin_y` | 画面宽 / 高的占比边距 |
| `font` | 字体名或路径；`""` = 自动 |
| `size` | 字号（短边占比） |
| `color` | 文字色 |
| `stroke` / `stroke_color` | 描边宽（短边占比）/ 描边色 |
| `plate` | `pill` = 圆角底板 |
| `plate_color` / `plate_padding` | 底板色（半透明）/ 内边距 |
| `opacity` | 整层透明度 |
| `rotate` | 整块文字旋转角（绕自身中心，不裁画面） |
| `max_width` | 换行阈值（画面宽占比；CJK 按字、拉丁按词归行） |
| `align` | 对齐 |
| `line_gap` | 行距 |

**文本来源** `text_from` = `outfit_label` / `pose_tag` / `variant_id` / `fixed`。

语义：`POST /runs/{id}/overlay` = `charvar overlay <run_id> --overlay <preset> [--text-from …] [--items 0,1]`。

## 字体解析顺序

1. `presets/overlays/fonts/` 里的文件
2. 系统候选：macOS PingFang / Hiragino、Linux Noto CJK、Windows 雅黑

`font: ""` = 自动。要跨机稳定就把字体文件放进 `fonts/`，
**只放可再分发的开源字体（OFL 系安全）；花字/美术字体的版权要单独确认**。
