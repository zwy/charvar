# 音乐通路（OpenRouter Lyria 3）

「给一段提示词出一行歌曲/曲子」的独立通路，与语音（`docs/语音通路.md`）、图片页、视频页
同构：不进主体档案 6 槽位、不跑预设批量、不落 runs 表。第一期只接 OpenRouter。

## 客户端（`charvar/openrouter_music.py`）

API 形态（2026-11 官方文档 + 实测，与语音/生图/视频三条通路都不同）：

- **没有独立端点**，走普通 `POST /api/v1/chat/completions`：
  body = `{model, messages, modalities: ["text","audio"], stream: true}`。
- **`stream: true` 必开** —— 不带流式直接 400（`Audio output requires stream: true`）。
- SSE 分片在 `choices[0].delta.audio`：`.data`（base64 片段，**按顺序拼接后一次 decode**，
  别逐段 decode）+ 可选 `.transcript`；`delta.content` 的文本段落（Lyria 的曲目说明）
  一并收集进 manifest；`data: [DONE]` 终结。
- 终末 `usage` 块带 `usage.cost` **实收费用** —— 与视频通路一样回写实价。
- 目录：`GET /api/v1/models?output_modalities=audio`（生图/视频/语音之外的**第四份缓存**，
  `data/openrouter/music-models.json`），复用 openrouter_image 的锁与原子写。
- **出口必须走系统代理**（2026-11-23 实测）：Lyria 的 provider 有地区限制，OpenRouter
  按请求**出口 IP** 判区，本机直连被 403（`This model is not available in your
  region.`）；走系统代理出口后 200（746KB mp3、实收 $0.04）。代理链：请求显式 >
  env `OP_MUSIC_PROXY` > macOS 系统代理（`urllib.getproxies()` 自动跟随系统端口，
  **不写死 QuickQ 端口**）> 直连（此时 Lyria 报 403，目录列表不受影响）。
  httpx 仍 `trust_env=False`（不信 shell 环境变量），代理是**显式参数**传入。
  这与生图/语音/视频「一律 bypass 代理」的红线**相反**，只限本通路。
- 预估价只能从目录条目 description 抽（`$0.04 per clip` / `$0.08 per song`）——
  `pricing.prompt/completion` 恒 0（一口价按次计费，不能按 token 算）。
  预估与实收两层分开记：`cost`（估）/ `cost_real`（实收）。
- 容器按魔数嗅探（复用 `openrouter_tts.sniff_audio_ext`）：Lyria 实测**完整 MP3**
  （30s 192kbps）。裸流（`gpt-audio` 按 `audio.format` 可出 pcm16 等无容器裸字节数）
  第一期不支持——采样率信息流里拿不到，`finalize` 直接 ParseError 提示换出 mp3 的模型。
- `audio: {voice, format}` 配置（gpt-audio 系才认，Lyria 不发）客户端支持透传，
  第一期 CLI/网页不暴露。
- `seed`：目录 `supported_parameters` 声明了才发，显式给才发，不引入随机源。
- 目录模型当前：`google/lyria-3-pro-preview`（整曲 $0.08）、`google/lyria-3-clip-preview`
  （30 秒 $0.04）、`openai/gpt-audio` / `gpt-audio-mini`（对话式，非音乐）。

## 编排层（`charvar/adhoc_music.py`）

镜像 `adhoc_tts.py`：

- `MusicRequest`：prompt / model / seed（空串=不发送，非法整数提交前拦）/ out。
- 落盘：`data/generated/adhoc_music/{id}/original/000000.mp3|wav|…` + manifest.json，
  失败也留痕。run_id `music_` 前缀 + `^music_[A-Za-z0-9_.-]+$` 严格正则（防 `..` 拼路径，
  同 tts/adhoc，别退回 `assets.safe_run_id`）。
- **同步**一步到终态（像语音），没有 status 轮询；但整曲生成可能要几分钟，
  超时默认 `OP_MUSIC_TIMEOUT` 或 600s（语音是 300s）。
- manifest `result` 记：model / seed_sent / transcript / text_content / ext /
  duration_s / size_bytes / cost / cost_real / duration_ms。
- 时长复用 `adhoc_tts._audio_duration`（ffprobe，失败 None）。

## 入口三处同语义

- CLI：`charvar music openrouter`（`--prompt/--prompt-file/--model/--seed/--timeout/--out/--json`）
  与 `charvar music models`。
- 网页：顶栏「音乐」页签（`web/static/music.html` + `music.js`），后端 `/music/*`
  （`charvar/api.py`）。路由纪律同 /tts：`/music/models`、`/music` 必须在
  `/music/{run_id}/…` 之前。
- skill：`skills/charvar-skill/`（`music` 命令段）。
- **改参数名或输出格式时三处同步**（CLI、网页、skill）。

## 默认链

模型：请求显式 > 设置页「OpenRouter 音乐」（DB）> env `OP_MUSIC_MODEL` > 兜底
`google/lyria-3-clip-preview`（便宜档；pro 整曲 $0.08 想要完整歌时显式选）。
API key 与生图/视频/语音同链路（`OP_API_KEY` / 旧 `OP_IMAGE_API_KEY` / `LLM_API_KEY`）。
HTTP 超时：请求显式 > `OP_MUSIC_TIMEOUT` > 600s。
出口代理：显式 / `OP_MUSIC_PROXY` > macOS 系统代理 > 直连（见上「出口必须走系统代理」）。

设置页组：设置卡片「OpenRouter 音乐」，只有「默认模型」（seed/格式不适合设全局默认），
`/settings` 键 `openrouter_music`，读接口带 `openrouter_music_default_model` 占位提示。

## 第二期候选

- 图片引导（Lyria 目录声明 `text+image -> audio`，拿图引导风格；chat/completions 的
  content 数组发 `image_url` data URI，与视频通路 base64 直传同姿势）。
- 裸流容器支持（`gpt-audio` 系）—— 需先实测 OpenRouter 流里是否有 format/采样率元信息。
- `audio.voice/format` 参数暴露到 CLI/网页。
- 音频参考（歌声驱动/翻唱类模型出现时接 input_audio 参考音频）。
