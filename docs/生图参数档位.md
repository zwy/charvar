# 生图参数档位（预设页 / 图片页面板约定）

预设页（gen.js）与图片页（adhoc.js）共用的参数档位约定，真源 = 代码与模型清单。
**只写当前有效定义**。工作约定见仓库根 `AGENTS.md`。

档位数据来源：

- OpenRouter 按 `data/openrouter/api-response.json` 的 `supported_parameters` 动态加载
  分辨率 / 质量枚举（同图片页）；即梦模型目录两表放 `web/static/tables.js`
  （gen.js 与 adhoc.js 共用，别再各写一份）。

## 几条约定（两边页面一致）

- **ComfyUI 没有 provider 枚举**，档位固定 charvar 的 `1k`/`2k`（2k = Qwen 官方
  ~4.2MP 像素，见 AGENTS.md「2K 官方像素表」条）。
- **OpenRouter 的模型不在面板里选**，跟设置页的 `t2i`/`i2i` 组默认（带参考图 =
  i2i 组）；分辨率 / 质量取该模型清单的枚举，没有就不显示。
- **即梦**：模型版本下拉空值 = 跟随设置页（`DREAMINA_IMAGE_MODEL`）；「跟随设置
  默认」要**真跟随**（空值发出去，后端才用设置页/env），不能名义上跟随、实际发
  硬编码的 2K。
- **即梦带参考图**时从模型下拉去掉不收参考图的档（`DREAMINA_IMAGE_MODELS` 的
  `refMax`，放 `tables.js` 共享）。
- **档位选择要记住**：切供应商再切回来别重置（`state.comfyTier` /
  `adhocState.comfyTier` / `state.orResolution`）。
