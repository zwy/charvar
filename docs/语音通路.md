# Playground 语音通路(OpenRouter TTS)

`charvar/adhoc_tts.py` 是「给一段文本出一段音频」的 Playground 通路,只接 OpenRouter
(`charvar/openrouter_tts.py` 客户端);与出图(`adhoc.py`)、出视频(`adhoc_video.py`)
同构:网页与 CLI 是同一套参数语义、同一套落盘、同一份 manifest;不进主体档案 5 槽位、
不跑预设批量、不落 runs 表。后续可能补本地/其他供应商,`backend` 字面量与 provider
子命令型 CLI 已留位。

## 与视频通路的关键差异:同步

`POST /api/v1/audio/speech`(OpenAI Audio Speech API 兼容)一次请求直接返回
**原始音频字节流**(不是 JSON),没有视频那套「提交 202 → 轮询 → /content 下载」三段:

- `generate()` 一步到终态;web `/tts/generate` 等音频字节返回后再响应(几十秒封顶,
  文本越长越慢),**没有 `/tts/{id}/status` 轮询端点**;
- CLI `charvar tts openrouter` 命令块到音频落盘,`--timeout`(默认 300s)只是 HTTP 超时;
- 失败也留痕:manifest `status=failed` + error(历史列表看得见失败原因)。

## 落盘

`data/generated/adhoc_tts/{id}/`(original/ + manifest.json):

- `original/000000.wav|mp3`:**落盘永远是可播的** —— 上游 HeyGen 只出裸 PCM
  (`audio/pcm;rate=44100;channels=1` 这类响应头),按响应头的 rate/channels 用
  标准库 wave 封装成 WAV;MiniMax 等 mp3 模型原样落 mp3。没有 thumbs(音频没有海报帧)。
- manifest:完整请求 + `X-Generation-Id`(响应头)+ 目录价估算 cost。

## API 要点(2026-10-28 实测)

- **模型目录没有独立端点**:`/api/v1/audio/models` 是 404,走标准
  `GET /api/v1/models?output_modalities=speech`,缓存
  `data/openrouter/speech-models.json`(与生图 api-response.json / 视频
  video-models.json 是三份独立缓存)。目录条目带 `supported_voices` 与
  `pricing.prompt`($/token ≈ $/字符;heygen-voice-1 $15/M、turbo $4/M、turbo:free 0)。
- **voice 实测必填**:heygen 不带 voice → `400 "An explicit voice is required unless
  input_references carries a reference recording."`;minimax → `400 "An explicit voice
  is required for this TTS provider."`。处理:目录枚举非空时请求空值**自动取枚举第一项
  兜底**(与视频页「默认取第一项」同策略);枚举为空的模型(fish/seed)不发送,
  交 provider 裁决。voice 超枚举是 `404 Unknown voice "X"`,不重试。
- **格式协商**:`response_format` 只有 mp3/pcm;给错 400 话术
  `HeyGen Voice only supports response_format "pcm".` /
  `MiniMax TTS only supports response_format="mp3" ...`,可正则提取合法值。
  求解顺序:**请求显式 > 探测缓存 > 静态表 > 不发(API 默认 pcm)**;
  探测缓存 `data/openrouter/tts-capabilities.json`(值级 `{model_id: {"response_format":
  "mp3"}}`,与生图 capabilities.json 的参数名级语义不同,别混用);静态表只有
  heygen/→pcm、minimax/→mp3、google/→pcm(官方文档明文声明)。被拒时按话术换值重试并记档。
- 上限:HeyGen 系(slug `heygen/` 前缀)单次 **5000 字符**(官方声明,实测一致),
  `adhoc_tts.validate` 提交前按码点拦;其他模型上限未知,不预检,交 provider(400 原样报)。
- 响应没有费用头:cost 按目录 `pricing.prompt` × 字符数估算,只做展示(与视频
  「预计 ≈」同一口径)。

## 入口(三处同语义)

- CLI:`charvar tts openrouter`(`--prompt`/`--prompt-file`/`--voice`/`--model`/
  `--format`/`--out`/`--json`)+ `charvar tts models`(模型/voice/每百万字符价目);
- 网页:顶栏「语音」页签(`web/static/tts.js`),后端 `/tts/*`(`charvar/api.py`,
  同步端点);前端 voice 下拉随所选模型 `supported_voices` 联动,枚举空收起;
  HeyGen 系前端计数 `N/5000`;
- 设置页:「OpenRouter 语音」组(`openrouter_tts` 键)只配默认模型;voice/格式不进
  配置(voice 随模型枚举变、格式自动协商)。

改 `charvar/adhoc_tts.py` 的参数名或输出格式时,CLI、网页、skill 三处都要同步。

## 配置与默认链

- 模型:请求显式 > 设置页「OpenRouter 语音」组(DB)> `OP_TTS_MODEL` env >
  免费档 `heygen/heygen-voice-1-turbo:free`;
- API key 与生图同链路(`OP_IMAGE_API_KEY` / `LLM_API_KEY`);
- HTTP 超时:`OP_TTS_TIMEOUT`(默认 300s)。
