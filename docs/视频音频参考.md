# 视频音频参考（OpenRouter 通路）

2026-11-22 实测口径。AGENTS.md 预算已满，细则按此文件维护（红线只留一句）。

## 通路

「给一段音频出一段对口型视频」的参考走法：音频跟参考图/参考视频一样进
`input_references`，类型 `{"type": "audio_url", "audio_url": {"url": <dataURL>}}`
（官方示例格式，图 `image_url` + 音 `audio_url` 同列表）。

- CLI：`charvar video openrouter --audio <path>`，≤1 条；`charvar video openrouter --help`。
- 校验：`openrouter_video.sniff_audio_ref` 按魔数判容器（mp3 / m4a・mp4 / wav / ogg），
  不按后缀；`adhoc_video.validate` 提交前查存在性 + 魔数，即梦通路显式拒绝。
- 编码：`encode_audio_reference` → data URL，原样发、不压缩（音频没做 reference_images 预处理）。
- manifest 记 `request.audio_path`。

## heygen avatar 系（音频驱动对口型）

`heygen/heygen-avatar-6-turbo`（$0.05/s @1080p、$0.0875/s @2K，2026-11-22 实收
$0.0488/s ≈ 目录价；注意与 heygen-video-1 的「实收=目录一半」对账结论不同，逐模型实测缓存为准）。

- 输入契约：**恰好 1 段音频 + 1 张参考图（或 1 段同人参考视频）**；1 段 audio 没给会被拒。
- 时长**由音频定**：不收 `duration`、`aspect_ratio`、`size` —— 画幅跟随参考媒体、
  时长跟随音频。CLI 里 `--aspect ""` 传空串跳过发送；发错了 provider 400 一次点名多参数，
  `openrouter_video._rejected_video_params` 会按「does not support …」段解析后整批降级重试。
- 成片时长略短于音频（0.1s 量级截尾，provider 正常行为）。
- prompt 是**动作提示**（它读音频的语气节奏驱动表情与动作）。
- 唯一放行透传参数 `motion_expressiveness`（调动作幅度，未接面板）。

## 预检（402 坑）

OpenRouter 对视频预检「最大花费 ≥ 可用账户 credits」，**预检不吃请求里的
duration**：对音频定长类模型按保守上限估价，门槛在 ($10.5, $20.5]
（2026-11-22 实测两次 402 后充到 $20.5 通过）。余额够时同样的请求直接通过。
真价远低于预检估价 —— 撞 402 先查账户 credits（`GET /api/v1/credits`），
充值即可，不是参数问题。

## 网页（已接）

「视频」页签有「音频参考」区（参考生视频页签：`video-arefs-block`，与参考视频区
对称）：`POST /videos/audio-references` 上传暂存（魔数判后缀 mp3/m4a/wav/ogg，
`_arefs/` 暂存池，成片 ready 或删除 run 时清掉）、`GET /videos/audio-reference/{id}`
试放、`DELETE /videos/audio-references/{id}` 删除；请求体 `audio: {staged_id}`
→ `VideoRequest.audio_path + staged_audio_ref_ids`，语义与参考图/参考视频一致。

- 区块只在「OpenRouter × 目录 `supports_audio`（id 含 avatar，`heygen/avatar-iv` /
  `heygen-avatar-6*`）」时显示；即梦侧不亮（后端 validate 显式拒绝）。
- avatar 输入契约前端提交前拦：音频在而参考图/参考视频空 → 提示先在「参考图」区
  加人物图（首帧不算 —— frame_images 与 input_references 是两路）。
- 面板档位不必动：avatar 系时长/画幅枚举为空时控件已收起；发了多余参数由
  `_rejected_video_params` 整批降级。
