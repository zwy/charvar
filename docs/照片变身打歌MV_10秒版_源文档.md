# 照片变身打歌MV｜10秒版制作文档

版本：V1.0 · 10秒连续齐舞版  
整理日期：2026-11-07  
用途：抖音单张照片特效；包含首帧图提示词与10秒视频提示词。  
整理原则：沿用已确认的首帧提示词，10秒视频提示词保留上一轮完整原文，不再改写。

## 1. 使用流程

1. 上传用户单人人像照片，作为图片阶段的 `素材1`，使用提示词A生成首帧图。
2. 检查本人辨识度、妆容、裁切和舞台背景。已有合格首帧可直接复用，不必重做。
3. 将生成的首帧图作为视频阶段的 `素材1`，使用提示词B生成10秒视频。
4. 视频阶段的 `素材1` 是首帧图，不是用户原始照片；两阶段的素材名称相同，但对应图片不同。

## 2. 参数与固定方案

| 项目 | 内容 |
|---|---|
| 图片与视频画幅 | 16:9横屏 |
| 视频时长 | 10秒 |
| 视频结构 | 四镜头，2秒＋2秒＋3秒＋3秒 |
| 人物数量 | 1名主角＋8名伴舞，共9人 |
| 主角服装 | 粉白星糖款：珍珠白上衣、樱粉短外套、胸前蝴蝶结、银边粉白百褶短裙、白色短靴 |
| 伴舞服装 | 白色主体、浅粉点缀的简化打歌服 |
| 舞台 | 粉蓝金色华丽舞台、水晶装饰、层叠拱形灯框、中央背景屏 |
| 背景文字 | READY → SHINE |
| 身份稳定设计 | 主角近处亮相，伴舞后方展开；不从远处人群走近，不甩头、不转身 |
| 收尾 | 约9秒统一收势，保留自然余摆，不切黑 |

生成界面中的时长选择10秒，画幅选择16:9；首帧选择高分辨率输出。

## 3. 10秒时间轴

| 时间 | 画面与动作 | 文字与镜头 |
|---|---|---|
| 0–2秒 | 贴脸对视、单次暖金扫光、微笑展开 | 固定极近特写，无文字 |
| 2–4秒 | 主角近处亮相，伴舞向后展开为V字，立即进入踏步摆臂 | 固定膝上中景，READY出现 |
| 4–7秒 | 全员左右跨步、斜上出臂、小跳并持续律动 | 固定全身中远景，READY熄灭 |
| 7–10秒 | 继续齐舞，约9秒亮相收势，最后一秒自然余摆 | 膝上中景小幅推进，约7.5秒SHINE出现 |

## 4. 提示词A：首帧图

输入：用户上传的人像照片，记作 `素材1`。  
输出：16:9横屏、高分辨率首帧。

```text
以素材1中的人物为唯一身份参考，生成16:9横屏打歌MV首帧。保持本人五官、脸型、肤色及发型发色，不换脸、不重塑五官。

极近距离面部特写，脸部充满画面，允许裁去部分额头或下巴，双眼、鼻子与嘴巴完整清晰。画面仅包含面部与局部发丝，脖子、肩膀、锁骨及任何衣服、领口、肩带均不得入画，不为展示背景而拉远镜头。

日式idol舞台妆：轻薄透亮底妆、自然棕色眼线、根根分明的睫毛、细腻珠光眼影、柔粉腮红与水润粉色唇妆；妆容精致清甜，保留本人辨识度。直视镜头，嘴角轻扬。

背景固定为华丽的粉蓝金色打歌舞台：对称灯阵、水晶装饰与层叠拱形灯框，在脸部边缘虚化呈现，不出现其他人。

cinematic live-action，真人实拍电影感画质；high-key bright lighting，高调明亮柔光，保留自然皮肤与发丝细节，色彩清透粉嫩，不泛白、不过度磨皮。无文字、Logo、水印。
```

## 5. 提示词B：10秒视频

输入：提示词A生成并验收通过的首帧图，记作 `素材1`。  
输出：10秒、16:9横屏视频。

```text
以素材1为首帧，生成10秒、16:9横屏、四镜头的日式偶像打歌MV。主角全程为素材1中的同一个人，保持五官比例、脸型、肤色、妆容、刘海、分缝、发色及可见发束轮廓一致。舞台造型仅改变服装，不重新设计脸和发型，头发只随动作自然摆动。

cinematic live-action，真人实拍电影感画质；high-key bright lighting，高调明亮打光（画面明亮通透、阴影浅、对比柔和，色彩清透粉嫩）；全片同一调色与光线风格，任何镜头不变暗、不变灰、不换画风。动作轻快、有力度、自然连贯，不以倍速或抽搐表现活力。

【服装与舞台】
主角身穿珍珠白舞台上衣、樱粉色短外套、胸前缎带蝴蝶结、银边粉白百褶短裙与白色短靴，领口完整、不露腰，全片服装一致。8名成年伴舞面容各异，不复制主角，身穿白色为主、浅粉点缀的简化款打歌服，装饰少于主角。

延续首帧中的粉蓝金色华丽打歌舞台：对称灯阵、水晶装饰、层叠拱形灯框、中央背景屏与柔和反光地面。正面柔光始终照亮主角面部，背景灯光随节奏变化，不频闪、不遮脸。群舞镜头中，主角始终位于中央前景，伴舞位于两侧后方，不遮挡、不顶替主角。

【镜头一｜0–2秒：贴脸对视】
从素材1直接接续，固定极近面部特写，允许裁去部分额头或下巴，双眼、鼻子与嘴巴完整清晰，脖子、肩膀及任何衣服均不入画。主角直视镜头，嘴角逐渐展开成明亮微笑。一道暖金色光带在约1秒内从画面一侧平滑横扫整张脸，单次扫完，不频闪、不往复；扫过处眼瞳亮起高光、脸颊提亮、发丝边缘泛起金色光泽，随后回到柔和定妆光。微笑到高点时随强拍切镜，不提前拉远。本镜无文字。

【镜头二｜2–4秒：READY，登场即起舞】
硬切正面膝上中景，主角已位于中央前景，面部清楚，延续上一镜同一张脸、同一发型。8名伴舞左右各4名，分布在两侧后方。镜头固定，主角不从远处人群中走近。

切镜强拍处，背景屏上方亮起超大圆角粗体大写“READY”，珍珠白字面、樱粉色厚边，整词轻弹到位后稳定显示，不遮挡头部。

主角向前迈一小步并打开双臂，伴舞同步向两侧后方开步，形成以主角为最前端的宽V字。开臂后立即接左右交替踏步，双肘在肩线下方打开、收回，膝盖随拍轻弹。全员连续律动，不停下来摆姿势。主角保持正脸朝镜头，手臂避开面部。

【镜头三｜4–7秒：全员齐舞，动作爆发】
切稍宽的正面中远景，以展示主角全身为限，不切远距离大全景。READY熄灭。主角仍在中央前景，8名伴舞保持两侧后方的宽V字。镜头固定，不横移、不环绕。

9人连续齐舞：向左侧跨步并向左斜上出臂，随即向右侧跨步并向右斜上出臂；接一次轻快小跳，双臂向高V字展开，落地屈膝回弹，继续踏步接下一镜。伴舞同步呼应，动作整齐有力度，不站着等待、不交叉换位。主角头部相对稳定，不甩头、不转身，手臂不经过脸前。本镜无文字。

【镜头四｜7–10秒：SHINE，最后一拍亮相】
切正面膝上中景，主角留在原位，不向镜头走近。全员延续踏步律动，双臂随强拍向斜上方展开。

约7.5秒，背景屏上方出现超大圆角粗体大写“SHINE”，与READY使用同一字体、尺寸略大，粉色细闪字面、珍珠白亮边。整词快速放大到位，边缘掠过一次光泽后稳定显示至结束，不遮挡主角面部。

文字出现后，全员继续左右踏步与肩侧摆臂；约9秒最后重拍，主角落稳，双臂舒展打开后收至腰侧，轻轻歪头，直视镜头灿烂微笑。伴舞同时在两侧后方微屈膝、展开手臂，以对称低位造型衬托主角。镜头仅小幅推进至腰部以上，最后一秒保留呼吸、发丝与裙摆余摆，不完全冻结，不切黑、不变暗。

【音乐与声音】
明亮轻快、富有弹跳感的J-pop电子流行器乐，清亮合成器、弹跳贝斯、拍手与电子鼓推动节奏。2秒切镜进入主律动，4秒齐舞加强鼓点，约7.5秒SHINE配合开臂重音，约9秒统一收势，最后留短促明亮尾音。音乐为主，轻微保留舞鞋落地与衣料摆动声，无对白，不突出喘息。

【统一约束】
主角身份、发型、服装和舞台跨镜头保持一致，四肢与手指结构自然连贯，人物不相互穿插。两处英文准确拼写，固定显示在舞台背景屏上，不作为前景悬浮字幕，不逐字飞入、不持续跳动。除“READY”“SHINE”外，无其他文字、字幕、Logo或水印。
```

## 6. 验收清单与版本状态

### 首帧图

- 仍是上传照片中的本人，未替换成统一偶像脸。
- 双眼、鼻子与嘴巴完整，允许裁去部分额头或下巴。
- 脖子、肩膀、锁骨、衣服、领口和肩带均未入画。
- 日式idol妆容与粉蓝金舞台背景符合设定。

### 视频

- 总时长10秒、16:9横屏，四镜头顺序正确。
- 重点检查约2秒首次切镜后，五官、脸型、刘海、分缝与发色是否延续首帧。
- 主角直接位于中央前景，未从远处人群走近。
- 主角＋8名伴舞的数量及V字队形清楚；伴舞不复制、遮挡或替换主角。
- 登场后动作连续，齐舞不长时间等待；约9秒才统一收势。
- READY与SHINE拼写正确，位于背景屏，不遮脸，无其他文字。
- 服装、舞台与高调明亮实拍质感跨镜头一致。
