# 即梦视频通路（dreamina-canvas 画布版）

> 状态：2026-11-11 底层换血 —— 即梦官方主推画布 CLI `dreamina-canvas`（1.3.0
> 实测），旧 `dreamina` CLI 直发通路**已下线**（不再保留双轨）。
> charvar 侧 = `charvar/dreamina_video.py`（分派/校验/轮询）+
> `charvar/dreamina_canvas.py`（子进程基座/画布编排）+ `adhoc_video` 的
> dreamina 分支。对外 backend 名、参数名、manifest 结构、落盘布局不变。

## CLI 与登录

- 二进制 `~/.local/bin/dreamina-canvas`（解析链 `DREAMINA_CLI` env > PATH >
  `~/.local/bin/dreamina-canvas`；安装
  `curl -fsSL https://jimeng.jianying.com/canvas-cli/install.sh | bash`）。
- **没有 API key 可配**：鉴权 = 本机 `dreamina-canvas auth login` OAuth（失效
  报错 exit 11 → `DreaminaAuthError`，重跑 login 即可）。积分余额
  `dreamina-canvas auth account`（`availableCredits`，含临期明细）。
- **子进程必须剥掉本机代理变量**（ALL_PROXY 等）：上传/下载走 CDN，实测
  被代理劫持直接「data stream ended unexpectedly」且资源 id 卡死 ——
  `dreamina_canvas._run_canvas` 统一处理，别在别处绕。

## 画布工作流（一次视频 = 一张画布）

```
canvas create charvar-video-<日期>-<随机8位>   → projectId + webUrl
resource upload --file <首帧/参考图/视频>       → resourceId（异步登记，轮询 resource get 到 success）
node create video --model --mode --prompt --ratio --resolution --duration --ref res:<rid>
node quote   → totalMaxCredits（报价，只看不扣）
node confirm --credit-ceiling ×1.2 → creditConfirmationToken
node run --credit-token --submit-id        → 真实扣费，submitId 即作业 id
operation status <submitId> --project-id   → state: running→succeeded/failed
node show / resource download              → 成片落盘（原样文件，扩展名按魔数嗅探）
```

- **幂等键**全是客户端 UUID：画布 `--project-id`、资源 `--resource-id`、
  运行 `--submit-id`。资源上传一旦「outcome 不可确认」（code 5 报 already
  submitted）该 id 就废了 —— charvar 每次尝试用新 id，失败换 id 重试。
- **积分闸门自动走完**：用户点「生成」= 授权扣费；quote 的
  `totalMaxCredits × _CREDIT_CEILING_PAD(1.2)` 作 ceiling 落 `node confirm`，
  报价与运行之间价格漂移会被 ceiling 拦下（exit 10/1 → 报「预算不足或价格
  变动」，不静默超预算）。
- **manifest.canvas** 落 `{project_id, web_url, node_id, mode}` —— refresh
  轮询与收片的**续查键**，缺了报 poll_error（旧直发 CLI 的作业没有画布
  id，无法续查，得重新生成）。
- 画布**不自动清理**（canvas CLI 没有 delete 子命令，只有删除节点）：画布全
  留在即梦网页里可复看，堆积了在网页端手动删。

### mode 分派（`dispatch_mode`）

| charvar 输入 | mode | 说明 |
|---|---|---|
| 只给提示词 | `t2v` | ratio 必填，缺省 16:9 |
| 首帧单图 | `first_last_frame`（1 帧） | ratio 缺省**从首帧图推断**（挑最接近档） |
| 首帧 + 尾帧 | `first_last_frame`（2 帧） | 引用按顺序 [首帧, 尾帧]（canvas 原生支持，旧 CLI 拦的是这个） |
| 参考图 / 参考视频 | `m2v` | 全能参考；各模型上限见表，至少一条 |
| 首帧 + 参考图/视频 | ✗ 报错 | i2v 语义只收一帧，宁可拦下 |

  `720P` —— 提交前大小写不敏感匹配、按目录字面值透传，**别归一**。
- 旧 CLI 的「2.5 图生拒显式 ratio」「1.0fast ratio 须与首帧一致」约束在
  canvas 目录已不存在 —— 不做提交前拦截，交上游裁决。
- 枚举两处同源：`charvar/dreamina_canvas.py` `_VIDEO_MODELS`（校验）+
  `web/static/tables.js` `DREAMINA_VIDEO_MODELS`（下拉）；目录真源 =
  `dreamina-canvas model list --type video`。
- 样片模式 `seedance_2.5_draft` 不进 charvar 目录。

## 与生图通路的共用与差异

- 共用 `dreamina_canvas` 基座（子进程 / 异常族 / 静态目录 / `CanvasRunner`）；
  异常族在 `dreamina_video` 按 `DreaminaVideoError` 别名引用。
- **无 seed**：请求值只记 manifest，绝不进命令行。
- **无逐条价目**：报价只有 `totalMaxCredits` 上界口径，`VideoResult.cost`
  对即梦恒 None。
- **提示词长度无目录级上限**：不做提交前拦截（只拦空串），上游报超长再校准。
- **首用合规确认**：提交返回 `AigcComplianceConfirmationRequired` → charvar
  翻译话式给网页端指引；`dreamina-canvas auth login` 救不回来（`explain_fail`）。
- **收片竞态兜底保留**：每路收片独立 download 目录、`original/` 已有成片直接
  复用、`_mark_if_open` 防另一路把 ready 抹成 failed（老坑，别退）。
- 产物扩展名按魔数嗅探（`video_file_ext`，CLI 落盘名不信任）。

## 异步作业与轮询

- web：`POST /videos/generate`（`backend: "dreamina"`）提交即返回 pending；
  manifest `job.id` = 画布 `submitId`；`refresh` 每 8s 打一次
  `operation status`（**单发查询**，绝不 `operation wait` 长阻塞 —— 会挂住
  web 轮询线程）；终态后 `_finalize_dreamina` 下载成片、抽海报。
- 状态映射：`running`→in_progress、`succeeded`→success→ready、
  failed/canceled→failed（error 带原样原因 + explain_fail）。
- CLI：`charvar video dreamina` 阻塞轮询（`--timeout` 默认 900s，超时作业
  仍在云端跑，manifest 保持 in_progress，网页可续查）。
- 参考视频暂存池 `_vrefs/` 两供应商共用；成片 ready 清池、失败保留以便重试。

## 配置

- 设置页「即梦视频」组只有 model 一项；DB 顶层键 `dreamina_video`。
- env：`DREAMINA_VIDEO_MODEL`（默认链：请求显式 > 设置页 DB > env >
  `seedance_2.0_fast_vip`；旧名 `seedance2.0fast_vip` 等自动映射）、
  `DREAMINA_VIDEO_TIMEOUT`（默认 900s）、`DREAMINA_RESOURCE_TIMEOUT`
  （参考素材登记处理，默认 120s）。
- 「跟随设置默认」要真跟随：网页模型下拉空值就发空到后端，后端走 DB > env 链。

## 实测记录

- **2026-11-04（旧直发 CLI）**：seedance2.0fast_vip / 5s / 720p = 30 积分
  （≈6 积分/秒），账号 standard 可跑。
- **2026-11-11（画布版上线首验）**：canvas create→upload→node→quote→confirm→
  run→status→download 全链实测；seedream_4.0 i2i 2K 图报 `maxCredits=1`
  （节点粒度报价，批量是逐 node 合计）；operation 终态词 `succeeded`；产物
  `resource download` 落盘 PNG（`dreamina-<rid>.png`，size+sha256 回执）。
