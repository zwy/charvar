# 视频文案（AI 文案）

给一条 AI 视频 run 生成「可直接发布的」中文短视频文案：标题 / 简介 / 话题标签。
**只写当前有效定义**——历史在 git log 里。工作约定与红线见仓库根的 `AGENTS.md`。

## 入口与产物

- **网页入口**：视频页「最近生成」卡的「AI 文案」按钮 → `POST /videos/{run_id}/copy`
  （`charvar/api.py`）；网页无独立页签。
- **产物**：`{"title", "intro", "tags"}` 三字段，写进该 run 的 `manifest.json` 的
  `copy` 键（`adhoc_video.save_copy`）。**已有文案重复点开 = 读 manifest 直出，不再调 LLM 不花钱**。
- **没有 CLI 子命令**：本期只走网页。给别的 run 重开文案也是同参数打这个端点。

## LLM 链

与配方侧 `scene_design.py` 同骨架：config（`settings_service.llm_overrides`，调用方传入）
> env；`llm.chat_json` 出 JSON，schema 固定（title/intro/tags 必填，additionalProperties=false）。
输入 = 该 run 的 `prompt`（视频提示词），**不传图**（不用视觉模型，慢且不必）。

校验集中在 `social_copy.validate_copy`（值级清洗，超限截断不给整单兜失败）：

| 字段 | 上限 | 说明 |
|---|---|---|
| title | 20 字 | 硬上限（用户拍板），超宽截断 |
| intro | 200 字 | |
| tags | 5 个 × 每个 12 字符 | 超出丢弃多余的 |

提示词要求（写死在 `social_copy._brief`）：标题口语化有钩子、不带引号/书名号、
不带 `#` 话题、不写「AI 生成」之类说明。
