# 角色变体提示词生成器 技术设计文档（v1）

> 用途：交给本地 Codex 实现。目标是把 ComfyUI 工作流「Character Dataset Builder – Q21」中的“主提示词 + 30 条角度/表情 + 随机背景光照”逻辑，抽离成本地系统里一个独立、可复用的模块。
> 本模块只负责**生成提示词**，不负责出图；但输出格式要能直接被 ComfyUI（逐行读取或 API 排队）消费。

---

## 1. 背景与目标

### 1.1 原工作流的提示词逻辑（逆向自 JSON）

```
最终提示词[i] = MasterPrompt + " " + AnglePrompt[i] + " " + Wildcard(背景, 光照)
i = 0..29，每次 ComfyUI 执行取一行，index 自增
```

- MasterPrompt：描述“参考图里的哪个主体 + 要保持的风格/体型/服饰”，例如 `Create an image of the woman in the character sheet in <image1>. Maintain style... Maintain physique.`
- AnglePrompt：30 行 = 3 种景别 × 8 个朝向（24 条）+ 6 条正面表情。
- Wildcard：`put them against a {gray|gradient blue white|red|...} background. The lighting is {...}`，由 Impact Pack 按种子展开。
- 原工作流已知缺陷（本系统需修复）：
  1. 拼接分隔符为空字符串，导致 `...camera.put them against` 粘连；
  2. 主体称谓（woman）硬编码在主提示词里；
  3. 随机背景/光照不可复现、不可追溯（没有记录每张用了什么）；
  4. caption 输出未接线，无法直接用于 LoRA 训练打标。

### 1.2 目标

| 编号 | 目标 |
|---|---|
| G1 | 输入一个“主体档案”，一键生成 N 条（默认 30）变体提示词 |
| G2 | 变体由**维度组合**生成（景别 × 朝向 × 表情 × 背景 × 光照…），而不是死写 30 行 |
| G3 | 同一输入 + 同一种子 → 完全相同的输出（可复现） |
| G4 | 每条输出附带结构化元数据（用了哪个景别/角度/背景/光照），并可生成训练 caption |
| G5 | 导出：TXT（每行一条，直接贴进 ComfyUI Text Multiline）、JSONL、ComfyUI API 批量排队 |
| G6 | 预设可编辑、可版本化（YAML 文件），内置原工作流 30 条作为默认预设 |

### 1.3 非目标（v1 不做）

- 不做图像生成、不做模型管理；
- 不调用 LLM 改写提示词（预留扩展点，见 §9）；
- 不做多用户/鉴权。

## 4. 数据模型（models.py）

```python
from pydantic import BaseModel, Field
from typing import Literal

class SubjectProfile(BaseModel):
    """主体档案：一个角色/人物/物体"""
    id: str                         # slug，如 "silver_witch"
    name: str                       # 显示名
    subject_noun: str = "person"    # 提示词中称谓：woman / man / girl / cat / character
    trigger_word: str | None = None # LoRA 触发词，如 "sw1tch"，用于 caption
    reference_tag: str = "<image1>" # 参考图占位符，对应 Qwen 编码节点
    style_lock: list[str] = []      # 要保持的风格："2d comic book style"
    identity_lock: list[str] = []   # 外貌：发色、瞳色、体型、痣、鼻环…
    outfit_lock: list[str] = []     # 服饰：保持不变的衣物配件
    extra: str = ""                 # 自由补充，直接拼到主提示词末尾

class VariantSpec(BaseModel):
    """一条变体的结构化描述（组合前）"""
    id: str                          # "full_l45"
    framing: Literal["full", "chest", "head"] | None = None
    angle: str | None = None         # "front","l45","r45","l90","r90","l135","r135","back"
    expression: str | None = None    # "neutral","smile",...
    text: str                        # 该变体的角度/表情提示词片段
    tags: list[str] = []             # 用于 caption 的短标签

class GenerateRequest(BaseModel):
    subject_id: str | None = None
    subject: SubjectProfile | None = None   # 二选一：引用已存档案 或 临时传入
    preset: str = "q21_default_30"
    seed: int = 0
    count: int | None = None                # None = 预设全部；小于总数时按 sampling 截取
    sampling: Literal["all", "first", "random"] = "all"
    randomize_background: bool = True
    randomize_lighting: bool = True
    fixed_background: str | None = None     # 指定则不随机
    fixed_lighting: str | None = None
    separator: str = " "                    # 修复原工作流的空分隔符问题

class PromptItem(BaseModel):
    index: int                  # 0-based，对应 ComfyUI index
    variant_id: str
    prompt: str                 # 最终完整提示词
    master: str
    variant_text: str
    background: str | None
    lighting: str | None
    caption: str
    meta: dict                  # framing/angle/expression/seed 等

class GenerateResult(BaseModel):
    run_id: str
    subject_id: str
    preset: str
    seed: int
    items: list[PromptItem]
```

### 5.2 `type: matrix` —— 维度组合（推荐，扩展用）

```yaml
name: matrix_basic
type: matrix
version: 1
master_template: (同上)
suffix_template: (同上)
dimensions:
  framing:
    full:  "Full-body shot of one {subject_noun}, entire figure visible from head to shoes, standing upright with arms relaxed at the sides"
    chest: "Chest-up portrait of one {subject_noun}, framed from the mid-chest to just above the head"
    head:  "Close-up headshot of one {subject_noun}, framed tightly on the head and shoulders"
  angle:
    front: "facing directly toward the camera"
    l45:   "body rotated 45 degrees toward the left side of the frame, three-quarter view"
    r45:   "body rotated 45 degrees toward the right side of the frame, three-quarter view"
    l90:   "body rotated 90 degrees to face the left side of the frame, full side profile view"
    r90:   "body rotated 90 degrees to face the right side of the frame, full side profile view"
    l135:  "body rotated 135 degrees away from the camera toward the left side of the frame, three-quarter rear view, face only partly visible"
    r135:  "body rotated 135 degrees away from the camera toward the right side of the frame, three-quarter rear view, face only partly visible"
    back:  "seen directly from behind, back fully toward the camera, face not visible"
  expression:
    neutral: "calm, neutral expression, relaxed face"
    smile:   "warm, genuine smile, happy expression"
    sad:     "sad expression, eyes looking downward, corners of the mouth turned down"
    pout:    "cute pouty expression, lips pushed forward in a soft pout"
    cringe:  "cringing expression, teeth clenched in an awkward grimace, eyes slightly squinted"
    silly:   "silly, playful expression, tongue sticking out, eyes wide and bright"
rules:
  # 生成顺序 = rules 顺序；每条 rule 是一个笛卡尔积
  - product: { framing: [full, chest, head], angle: "*" }          # 24 条
  - product: { framing: [head], angle: [front], expression: "*" }  # 6 条
exclude:
  - { angle: back, expression: "*" }   # 背面不加表情
join: ", "
end: "."
```

变体文本 = `framing + join + angle [+ join + expression] + end`，id = `{framing}_{angle}[_{expression}]`。

## 6. 核心算法（composer.py）

```
generate(req) -> GenerateResult
  1. subject  = 加载/校验 SubjectProfile
  2. preset   = preset_loader.load(req.preset)
  3. specs    = preset.type == list ? preset.variants : expand_matrix(preset)
  4. specs    = 应用 count + sampling（random 用 rng = Random(seed)）
  5. master   = render(master_template, subject)
  6. for i, spec in enumerate(specs):
        rng_i      = Random(hash((seed, spec.id)))   # 每条独立子种子 → 增删变体不影响其他条
        background = fixed_background or (rng_i.choice(bg) if randomize else None)
        lighting   = fixed_lighting  or (rng_i.choice(lt) if randomize else None)
        variant    = render(spec.text, subject)       # 支持 {subject_noun}
        suffix     = render(suffix_template, ...) 若 bg/lt 都为 None 则省略
        prompt     = normalize(join([master, variant, suffix], req.separator))
        caption    = caption.build(subject, spec, background, lighting)
        items.append(PromptItem(...))
  7. storage.save_run(result)
```

### 6.1 关键规则

- **可复现**：禁止使用全局 `random`；子种子用稳定哈希（`hashlib.sha256(f"{seed}:{id}")` 取前 8 字节），不要用 Python 内置 `hash()`（进程间不稳定）。
- **render**：用 `str.format_map` + 安全字典（缺失键保留原样并记录警告），不要用 eval/Jinja 执行任意代码。
- **lock 句子**：`style_lock=["2d comic book style","saturation levels"]` → `"Maintain 2d comic book style. Maintain saturation levels. "`；空列表输出空串。
- **normalize**：合并多余空格；确保句号后有空格；去掉 `..`；首尾 trim。
- **背面/遮挡变体**：当 angle ∈ {l135, r135, back} 时，caption 中不写表情标签。

### 6.2 caption 规则（caption.py）

```
{trigger_word}, {framing_tag}, {angle_tag}[, {expression_tag}], {background} background, {lighting_short}
例：sw1tch, full body, three-quarter view from left, gray background, soft window light
```

标签映射表写在预设 YAML 的可选 `caption_tags` 字段里，缺省用内置映射。

## 8. ComfyUI 集成（exporters/comfyui.py）

两种模式，v1 两者都实现：

**模式 A：TXT 粘贴（零改动）**
`prompts.txt` 每行一条**完整提示词**。在原工作流中把 Master Prompt 清空、把 wildcard 节点旁路，将 TXT 内容贴入 `Text Multiline`，队列次数 = 行数。

**模式 B：API 排队（推荐）**
1. 用户在 ComfyUI 中“导出 (API)”得到 `api_workflow.json`；
2. 配置映射文件，指明要注入的节点：
   ```yaml
   prompt_node: { id: "123", field: "prompt" }      # TextEncodeQwenImage21 的正向文本输入
   seed_node:   { id: "45",  field: "seed" }         # 可选
   save_node:   { id: "67",  field: "filename_prefix" }
   ```
3. 对每个 PromptItem：深拷贝 workflow → 写入 prompt、`filename_prefix = {subject}_{index:03d}_{variant_id}` → `POST /prompt`；
4. 记录返回的 `prompt_id` 到 SQLite，供以后关联图片与 caption。

注意：原 JSON 是 UI 格式且含子图，不能直接用于 `/prompt`，必须用 API 格式导出；节点 id 由用户配置，不要硬编码。

## 9. 扩展点（v1 留接口不实现）

- `VariantSpec` 新维度：`pose`（坐/蹲/走）、`camera`（俯拍/仰拍）、`outfit`（换装预设）——matrix 预设天然支持，只需加 dimension。
- `Rewriter` 协议：`rewrite(prompt, subject) -> str`，后续可接本地 Ollama/LLM 做润色或中译英。
- 预设继承：`extends: matrix_basic` + 覆盖部分维度。

---

## 10. 测试要求

1. `q21_default_30` 展开后正好 30 条，文本与原 JSON 逐字一致；
2. `matrix_basic` 展开后 30 条，id 唯一，顺序稳定；
3. 同 seed 两次生成结果完全相等；不同 seed 背景/光照分布不同；
4. 删除预设中第 5 条后，其余条目的背景/光照不变（子种子机制）；
5. 任意输出不出现 `.P`/`.p` 粘连、双空格、`{` `}` 残留；
6. `subject_noun="man"` 时输出中不出现 `woman`；
7. ComfyUI 导出：给定 mock workflow，注入后的字段正确，`filename_prefix` 唯一。

---

## 11. 验收标准

- `charvar gen --subject demo --seed 1` 在 1 秒内输出 30 条，三种格式文件齐全；
- 把 `prompts.txt` 贴进原工作流运行前两条，文本预览与 TXT 第 1、2 行一致；
- API 模式下 30 个任务成功进入 ComfyUI 队列，输出文件名与 caption 文件一一对应。

## 附录 A：示例主体档案

