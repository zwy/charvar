即梦 Dreamina 生图

走本机 dreamina-canvas CLI 画布工作流，没有 API Key，不暴露 seed；提示词上限按模型（seedream 4.x 2000 / 5.x 与智能图片 5000 / 美学 V8.2 1024，超限硬失败），生成消耗即梦积分。分辨率档按所选模型配对，选「跟随默认」就按默认模型的档位。

OpenRouter 视频

生效链：请求显式 > 这里 > OP_VIDEO_MODEL；时长 / 分辨率 / 画幅在「视频」页逐条选。

即梦视频（Seedance）

生效链：请求显式 > 这里 > DREAMINA_VIDEO_MODEL > seedance_2.0_fast_vip（720p / 4–15s，旧名自动映射）；时长 / 分辨率 / 画幅在「视频」页逐条选。

OpenRouter 语音

生效链：请求显式 > 这里 > OP_TTS_MODEL；voice 在「语音」页逐条选（缺省走枚举第一项）。
