提示：模型选完会按 api-response.json 里该模型的 supported_parameters 动态加载分辨率/质量档；该模型不支持的档会自动收起并重置为空。两个模式对齐 ComfyUI 的文生图 / 图片编辑 workflow：带参考图的生图（档案其余 4 槽、批量推送勾了参考图、Playground 带参考图）走「图片编辑」这组。分辨率/质量留空 = 用请求显式值 > 设置页 > env（OP_IMAGE_T2I_* / OP_IMAGE_I2I_*）的默认，且值要在所选模型声明的枚举里才真正发送。API Key 留空 = 用环境变量；同一家的 OpenRouter key 可以直接复用 LLM_API_KEY。OpenRouter 不支持负向提示词，参考图按勾选顺序对应提示词里的 the first/second… reference image。




即梦 Dreamina 生图








提示：即梦走本机官方 dreamina CLI，鉴权用 dreamina login 的登录态（这里没有 API Key）。即梦的模型都有编辑能力，不区分文生图 / 图片编辑配置组：带参考图自动走 image2image，不带走 text2image，共用这一组配置。即梦不暴露 seed；提示词上限 text2image 约 1600 字符、image2image 约 2000 字符（超限会硬失败）；生成消耗即梦积分/权益（仅限会员）。分辨率留空 = 请求显式值 > 设置页 > env（DREAMINA_IMAGE_RESOLUTION，默认 2K）。
