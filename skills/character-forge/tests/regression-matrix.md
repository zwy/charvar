## 自动检查覆盖的部分

`tests/run_checks.py` 覆盖 T06／T07／T13／T14／T15／T16／T17 的文档结构层面，以及：

- 旧正式交付条件不再作为生效规则存在（quality-checks.md 的废止说明除外）。
- 错误的字符换算与计费表述已清除。
- 交付模板中两项基础图各有独立位置。
- `submit` 代码块无占位符且符合预算；`component`／`template` 不参与预算。
- manifest 与实际文件一致，三处版本号同步。
- 夹具中标注的字符数与脚本实测一致。

## 明确未验证的部分

- **任何真实出图效果。** 两项基础图是否真的能让模型稳定产出四描绘、是否同一张脸、衣服结构是否跨视图一致，均需用户实际生图验证。静态检查无法判断。
- **具体模型的版式执行能力。** 分节写法、35%／65% 布局提示在目标模型上的实际表现未知。
- **宿主加载。** 技能在不同客户端的目录识别、相对引用读取与自动激活未在本仓库验证。
- **模式 B 的终端链路。** 单张照片进入、素材 ID 引用、不同人物复测，需要真实平台环境。
- **跨模型复现。** 提示词不承诺跨模型、跨参数一致复现。
- **助手实际看图能力。** 夹具中的「看图」是行为记录约定，不构成任何图像质量判断。
