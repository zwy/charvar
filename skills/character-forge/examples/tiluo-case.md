# 缇珞案例：两条风格路线的工作流示例

本案例仅说明工作方法，不把角色属性设为 Skill 默认。来源为作者此前的一次实操，包括用户请求、阶段反馈和两份角色模板整理过程。

> **这是一次历史实操记录，不是新版流程的逐项实测。** 它的步骤顺序与新版主线（全身正面定妆 → 同图设定板 → 资产交付）大体一致，但不是每一步都按新版规则单独跑过，也不能拿它证明新版任何一项要求已验证。案例特有的做法不自动推广为通用规则。

## 插画路线

用户提供尖耳黑短发成年女性的插画与原提示词，要求仅提取主体并补全缺失下半身。

1. 区分图中已有髻部与黑色裤子方向、尚未展示的腿部和鞋履。
2. 延续黄黑制服，提案黑色长裤和简洁低跟短靴，去背景与对白，做单人全身。
3. 用户认可后，提案保守背面结构与“左放大半身＋右正侧背全身”。
4. 拆分固定角色、风格、服装与场景，测试认真观察杯子的场景。
5. 用户认可后命名缇珞，整理插画版模板。

对照新版主线：第 2 步对应 S1 全身正面定妆，第 3 步对应 S3 同图设定板，第 5 步对应 S5 资产化。第 4 步的跨场景测试在新版中属于可选分支，不是正式交付的硬门槛。

## 真人路线

1. 保留同一角色设计方向，将插画表现转为自然真实摄影。
2. 先全身，用户认可后半身细化脸、发型与尖耳。
3. 采用已认可的真人结果作为后续身份依据，不继续每轮从插画重新解释脸。
4. 制作真人多视角，再测试同一饮料场景，便于比较不同媒介下的角色延续。
5. 用户认可后另建真人版文档，不覆盖插画分支。

## 证据边界

会话中用户连续反馈认可，但生成结果图未在这些阶段实际附回供助手检查。应记用户反馈认可，不写成助手逐图验收或批量成功率已知。模型、种子、批次与可用数量未完整提供，不补造。

两份最终角色文档是整理版，包含合并、压缩与新增名字等变化。进一步复用应保存原始测试提示词与整理版的对应关系，不能将整理版自动标为原文已测。

## 可复用经验

- 一轮一个目标，认可后再推进。
- 每轮明确使用哪张图、它负责什么。
- 服装、面部身份、风格和场景分别处理。
- 缺失部分可以设计，但区分补全与原图事实。
- 风格转换创建新分支，并及时建立新分支基准。
- 用户认可的范围明确，不因一句“不错”扩大成全部通过。

## 本案例的适用范围

以上是本案例的做法与结论，不是模型通用规律。以下写法属于案例记录，不得升级为普遍规则：

- 本案例用“左放大半身＋右正侧背全身”作为同图设定板布局 → 不等于所有角色必须使用该布局，也不等于该比例是硬门槛。
- 本案例分节重写后，用户反馈布局满意 → 不等于不分节模型就不会执行版式任务。
- 本案例中全身基准与设定板都获得了认可 → 不等于其他角色可以跳过这两步。

## 不应照抄的内容

尖耳、蓝眼睛、黑短发、黄黑制服、太空背景、白杯子、成年女性体态、角色名以及半身加三视图布局，都是案例选择，不是所有新角色的强制要求。
